Safe Child 스마트폰 제어 및 외부 접속 시험 절차
작성일: 2026-09-16

============================================================
시험 목적과 진행 순서
============================================================

1차: 같은 Wi-Fi에서 모바일 접속과 사이트 차단·해제 확인
2차: DDNS, 인증서, 공유기 포트포워딩 구성
3차: 휴대폰 LTE·5G에서 외부 접속과 시간표 제어 확인

중요: 휴대폰은 조작용입니다. 실제 사이트 차단·해제 여부는
Safe Child가 실행되는 PC에서 확인합니다.
휴대폰 자체의 인터넷을 차단하는 기능은 아닙니다.

아래 IP와 도메인은 예시입니다. 실제 환경의 값으로 바꿔 입력하세요.

============================================================
시험 구성
============================================================

제어 대상       : Safe Child가 실행되는 Windows PC 1대
공유기          : 현재 사용 중인 SK브로드밴드 공유기
부모 휴대폰     : Chrome 또는 Safari, LTE·5G 사용 가능
PC 내부 IP 예시 : 192.168.35.100
외부 주소       : 본인이 등록한 DDNS 또는 도메인 주소
외부 포트       : TCP 47831
내부 포트       : TCP 47831
차단 시험 사이트: example.com

외부 접속 경로:
부모 휴대폰(LTE·5G) → 인터넷 → SK 공유기 → Safe Child PC

실제 환경 기록:
  공유기 모델명: ______________________________________
  PC 내부 IPv4: ______________________________________
  기본 게이트웨이: ___________________________________
  공유기 WAN IP: _____________________________________
  DDNS 주소: _________________________________________
  외부 포트: _________________________________________
  인증서 PFX 파일 위치: ______________________________
  인증서 만료일: _____________________________________

비밀번호는 이 시험 기록 파일에 적지 않습니다.

============================================================
STEP 1. 최신 프로그램 실행
============================================================

1. 기존 Safe Child가 실행 중이라면 앱의 관리자 모드에서 정상 종료합니다.
2. 다음 최신 실행 파일을 관리자 권한으로 실행합니다.

   C:\Users\Administrator\Downloads\proj\GITHUB\work\Safe_Child\bin\Release\net8.0-windows\SafeChild.exe

3. 처음 실행하면 관리자 비밀번호를 설정합니다.
   기존 설정이 있으면 현재 비밀번호로 관리자 모드에 들어갑니다.
4. 스마트폰 제어 탭을 엽니다.

주의:
이전에 만든 설치 파일에는 최신 변경이 들어 있지 않을 수 있습니다.
이번 시험에서는 위 실행 파일을 사용하세요.

정상 결과:
- 스마트폰 제어 탭에 '외부 접속 사용' 기능이 있습니다.
- 외부 접속 사용을 켜면 외부 주소와 인증서 입력란이 보입니다.

============================================================
STEP 2. PC 내부 IP와 네트워크 상태 확인
============================================================

1. PC에서 명령 프롬프트를 엽니다.
2. 다음 명령을 실행합니다.

   ipconfig

3. 실제 연결 중인 Wi-Fi 또는 이더넷 항목에서 아래 값을 기록합니다.
   - IPv4 주소: 공유기 포트포워딩의 대상 PC 주소
   - 기본 게이트웨이: 보통 현재 연결된 공유기 주소
4. Windows 설정 → 네트워크 및 인터넷 → 연결된 Wi-Fi 또는 이더넷에서
   네트워크 프로필을 '개인 네트워크'로 설정합니다.
5. 시험 중에는 PC가 절전 상태로 들어가지 않도록 설정합니다.
   시험 후 원래 절전 설정으로 복원합니다.

참고:
현재 앱의 Windows 방화벽 규칙은 개인·도메인 프로필에 적용됩니다.

정상 결과:
- PC 내부 IPv4 주소와 기본 게이트웨이를 확인했습니다.
- 집 네트워크 프로필이 개인 네트워크로 설정되어 있습니다.

Windows 안내:
https://support.microsoft.com/en-us/windows/experience/connectivity-networking/essential-network-settings-and-tasks-in-windows

============================================================
STEP 3. 같은 Wi-Fi에서 기본 접속 시험
============================================================

이 단계에서는 DDNS, 포트포워딩, 외부 인증서가 필요 없습니다.

1. 휴대폰을 PC와 같은 공유기의 Wi-Fi에 연결합니다.
   게스트 Wi-Fi는 피합니다.
2. PC의 스마트폰 제어 탭에서 '외부 접속 사용'을 끕니다.
3. STEP 2에서 확인한 PC 내부 IP를 선택합니다.
4. 'QR 연결 시작'을 누릅니다.
5. 휴대폰으로 QR을 스캔하고 브라우저에서 엽니다.
6. Safe Child 관리자 비밀번호로 로그인합니다.

인증서 안내:
내부 모드는 PC가 생성한 자체 인증서를 사용하므로 인증서 안내가
나타날 수 있습니다. PC가 표시한 내부 IP와 접속 주소가 정확히
일치하는지 확인하세요. 브라우저가 진행을 허용하지 않으면
경고 화면의 내용을 기록해 두세요.

정상 결과:
휴대폰에 다음 항목이 표시됩니다.
- 사이트별 보호
- 사이트 추가
- 모든 사이트 일시 허용

============================================================
STEP 4. 사이트 차단·해제 시험
============================================================

1. PC 브라우저에서 https://example.com 이 정상적으로 열리는지 확인합니다.
2. 휴대폰에서 '사이트 추가'를 선택합니다.
3. 다음 값을 입력합니다.

   사이트 주소: example.com
   차단 선택: 켬
   차단 시간: 항상 — 수동 차단

4. '저장하고 적용'을 누릅니다.
5. PC의 사이트 목록에 example.com이 추가되었는지 확인합니다.
6. PC 브라우저에서 해당 사이트에 새로 접속합니다.
7. 휴대폰에서 example.com을 편집하여 '차단 선택'을 끄고 저장합니다.
8. PC에서 해당 사이트에 다시 접속합니다.

정상 결과:
- 차단 선택 켬: PC에서 example.com에 접속되지 않습니다.
- 차단 선택 끔: PC에서 example.com에 다시 접속됩니다.

시험 조건:
- 전체 일시 허용이 종료된 상태여야 합니다.
- 시험 사이트가 기존 규칙과 중복되지 않게 합니다.
- 이미 열린 화면이 남아 있으면 브라우저를 완전히 종료한 뒤 재접속합니다.

이 단계까지 성공하면 모바일 화면, 로그인, 설정 저장,
PC 보호 적용의 기본 동작이 확인된 것입니다.

============================================================
STEP 5. 공유기 공인 IP와 PC 주소 예약 확인
============================================================

1. PC 브라우저에서 STEP 2의 기본 게이트웨이 주소를 엽니다.
2. 공유기 관리 화면에 로그인합니다.
   이때는 Safe Child 비밀번호가 아닌 공유기 관리자 비밀번호를 사용합니다.
3. 인터넷 상태 또는 WAN 상태에서 WAN IP를 확인합니다.
4. LAN 또는 DHCP 설정에서 PC의 IP 주소 예약 기능을 찾습니다.
5. PC가 계속 같은 내부 IP를 받도록 예약합니다.
   예시: 192.168.35.100

WAN IP 확인:
다음 범위이면 상위 공유기나 통신사 NAT가 있는지 확인해야 합니다.
- 10.x.x.x
- 172.16.x.x ~ 172.31.x.x
- 192.168.x.x
- 100.64.x.x ~ 100.127.x.x

일반적인 포트포워딩에는 공인 WAN IP가 필요합니다.
이중 공유기라면 상위 장비에도 전달 설정이 필요할 수 있습니다.
통신사 CGNAT 환경이면 공인 IP 사용 가능 여부를 통신사에 확인합니다.
SK 공유기의 정확한 메뉴명은 모델마다 다릅니다.

정상 결과:
- 외부에서 들어올 수 있는 공인 IP 경로가 있습니다.
- 대상 PC가 같은 내부 IP를 계속 받도록 설정되어 있습니다.

포트포워딩 조건 참고:
https://www.tp-link.com/us/support/faq/785/

============================================================
STEP 6. DDNS 주소 준비
============================================================

이미 사용하는 DDNS 주소가 있으면 그대로 사용합니다.

없는 경우의 예시:
1. No-IP 같은 DDNS 서비스에서 호스트 이름을 등록합니다.
2. PC에 해당 서비스의 Windows용 IP 갱신 프로그램을 설치합니다.
3. 등록한 호스트 이름을 갱신 프로그램에 연결합니다.
4. 갱신 대상이 집의 공인 IP인지 확인합니다.

No-IP Windows 갱신 프로그램 안내:
https://www.noip.com/support/knowledgebase/installing-the-windows-4-x-dynamic-update-client-duc

주소 확인:
PC의 명령 프롬프트에서 다음 명령을 실행합니다.
'본인의DDNS주소'를 실제 등록한 이름으로 바꾸세요.

   nslookup 본인의DDNS주소

결과에서 조회한 도메인의 IP 주소를 확인합니다.
출력 맨 위의 DNS 서버 주소와 혼동하지 않도록 합니다.

정상 결과:
DDNS 주소가 집의 공인 IPv4 주소로 조회됩니다.

============================================================
STEP 7. 외부 접속용 PFX 인증서 준비
============================================================

이미 해당 DDNS 주소용 PFX 인증서가 있으면 STEP 8로 넘어갑니다.

없는 경우 Windows에서 발급하는 한 가지 방법은 win-acme입니다.
아래는 HTTP 방식으로 도메인 소유권을 확인하는 절차입니다.

1. win-acme 공식 사이트에서 프로그램을 받아 압축을 풉니다.
   https://www.win-acme.com/manual/getting-started

2. 공유기에 인증 확인용 전달 규칙을 추가합니다.

   용도: 인증서 발급 확인
   외부 포트: TCP 80
   대상: Safe Child PC의 내부 IP
   내부 포트: TCP 80

3. Windows 방화벽에도 인증 확인용 TCP 80 인바운드 규칙을 추가합니다.
   방화벽 전체를 끄는 대신 다음 순서로 별도 규칙을 만듭니다.

   고급 설정 → 인바운드 규칙 → 새 규칙 → 포트 → TCP 80
   → 연결 허용 → 개인 프로필

4. wacs.exe를 관리자 권한으로 실행합니다.
5. 인증서 생성의 전체 옵션을 선택합니다.
   버전에 따라 메뉴 번호가 달라질 수 있으므로 이름을 기준으로 선택합니다.

   도메인 지정: 직접 입력 — 본인의 DDNS 주소
   소유권 확인: HTTP / Self-hosting
   저장 방식: .pfx file
   저장 위치: 본인이 관리할 인증서 폴더
   PFX 비밀번호: 별도로 정하고 보관
   IIS 설치 작업: 사용하지 않음

6. 안내에 따라 도메인 소유권 확인과 인증서 발급을 완료합니다.
7. 생성된 PFX 파일 위치와 만료일을 기록합니다.

정상 결과:
- 본인의 DDNS 주소에 대해 발급된 .pfx 파일이 있습니다.
- 해당 PFX 파일에 개인 키가 포함되어 있습니다.
- PFX 비밀번호를 알고 있습니다.

참고:
- HTTP 검증 요청은 외부 80번 포트로 들어옵니다.
- 외부 80번을 사용할 수 없으면 DNS 검증 등 다른 방식을 사용해야 합니다.
- PFX 저장 방식은 인증서, 개인 키, 인증서 체인을 함께 내보냅니다.
- 인증 확인용 80번 규칙을 시험 후 제거하면 같은 방식의 인증서 갱신 시
  다시 열어야 합니다.
- Safe Child 자체 접속은 STEP 8의 47831번을 사용합니다.
- Safe Child는 인증서를 자동 발급하지 않습니다. 갱신한 PFX를 적용할 때는
  스마트폰 연결을 중지하고 새 인증서를 선택한 뒤 다시 시작합니다.

HTTP 검증 안내:
https://www.win-acme.com/reference/plugins/validation/http/selfhosting

PFX 저장 안내:
https://www.win-acme.com/reference/plugins/store/pfxfile

============================================================
STEP 8. Safe Child용 포트포워딩 설정
============================================================

SK 공유기에 다음 규칙을 등록합니다.

규칙 이름: SafeChild
프로토콜: TCP
외부 시작 포트: 47831
외부 끝 포트: 47831
내부 IP: 실제 Safe Child PC 내부 IP
내부 시작 포트: 47831
내부 끝 포트: 47831
사용 여부: 사용

포트를 한 칸으로 받으면 47831만 입력합니다.
SK 공유기의 정확한 메뉴명은 모델마다 다릅니다.

정상 결과:
외부 TCP 47831 → Safe Child PC TCP 47831 규칙이 저장되어 있습니다.

============================================================
STEP 9. Safe Child 외부 접속 모드 시작
============================================================

1. 기존 스마트폰 연결을 중지합니다.
2. 앱의 관리자 모드에 들어갑니다.
3. 스마트폰 제어 탭에서 '외부 접속 사용'을 켭니다.
4. 외부 주소에 다음 형식으로 입력합니다.

   https://본인의DDNS주소:47831

   실제 DDNS 이름으로 바꾸며, 경로나 긴 접속 문자열은 입력하지 않습니다.

5. STEP 7에서 준비한 PFX 파일을 선택합니다.
6. PFX 비밀번호를 입력합니다.
7. 포트포워딩 대상인 PC 내부 IP를 선택합니다.
8. 'QR 연결 시작'을 누릅니다.

정상 결과:
- '외부 접속 대기 중'이라고 표시됩니다.
- 인증서 만료일과 공유기 포트 전달 정보가 표시됩니다.
- 외부 접속 QR과 전체 주소가 표시됩니다.

중요:
입력한 도메인 뒤에 긴 문자열이 붙은 접속 주소가 생성됩니다.
휴대폰에는 '접속 주소 복사' 또는 QR로 주소 전체를 저장해야 합니다.
도메인 주소만 입력하면 접속되지 않습니다.

============================================================
STEP 10. 휴대폰 LTE·5G 외부 접속 시험
============================================================

1. 휴대폰 Wi-Fi를 끕니다.
2. 상태 표시줄에 LTE 또는 5G가 표시되는지 확인합니다.
   집 밖으로 나갈 필요는 없습니다.
3. STEP 9의 QR을 스캔하거나 전체 접속 주소를 브라우저에 입력합니다.
4. Safe Child 관리자 비밀번호로 로그인합니다.
5. STEP 4의 사이트 차단·해제 조작을 다시 수행합니다.
6. 실제 차단·해제 결과는 PC 브라우저에서 확인합니다.

비밀번호 구분:
- 공유기 관리자 비밀번호: 공유기 설정 화면에서 사용
- PFX 비밀번호: PC에서 외부 연결 서버를 시작할 때 사용
- Safe Child 관리자 비밀번호: 휴대폰 제어 페이지 로그인에 사용

외부 로그인에는 Safe Child 관리자 비밀번호를 사용합니다.
마스터 비밀번호는 외부 로그인에 사용할 수 없습니다.

정상 결과:
- Wi-Fi가 꺼진 LTE·5G 상태에서 제어 페이지가 열립니다.
- 사이트 목록이 표시됩니다.
- 휴대폰에서 변경한 차단·해제 상태가 PC에 적용됩니다.

============================================================
STEP 11. 시간표와 일시 허용 시험
============================================================

모든 시험은 휴대폰 Wi-Fi를 끈 상태로 진행합니다.
시간표는 휴대폰 시각이 아니라 PC 현지 시각 기준입니다.
휴대폰 표시 갱신과 PC 적용에 몇 초 정도 여유를 두고 확인합니다.

[시험 A: 요일별 반복]
1. example.com의 차단 선택을 켭니다.
2. 차단 시간을 '요일별 반복'으로 선택합니다.
3. 오늘 요일만 켜고 다른 요일은 끕니다.
4. 시작을 현재 PC 시각보다 2분 뒤, 종료를 4분 뒤로 설정합니다.
   예: 현재 14:00 → 오늘 14:02~14:04
5. 저장하고 PC에서 접속 상태를 확인합니다.

정상 결과: 시작 전 허용 → 지정 시각에 차단 → 종료 시각에 해제
참고: 첫 시험은 자정 직전을 피하면 결과를 확인하기 쉽습니다.

[시험 B: 경과 시간]
1. 차단 선택을 켭니다.
2. 차단 시간을 '지금부터 일정 시간'으로 바꿉니다.
3. 시간을 1분으로 입력하고 저장합니다.

정상 결과: 즉시 차단되고 약 1분 후 해제됩니다.

[시험 C: 전체 일시 허용]
1. example.com을 '항상 — 수동 차단'으로 설정하고 차단 선택을 켭니다.
2. PC에서 실제로 차단되는지 확인합니다.
3. 휴대폰에서 전체 허용 시간을 1분으로 적용합니다.
4. PC 접속 상태와 만료 후 상태를 확인합니다.

정상 결과: 1분 동안 접속 가능 → 만료 후 다시 차단

[시험 D: 즉시 보호 복원]
1. 전체 일시 허용을 다시 적용합니다.
2. 허용 중에 '허용 종료 · 보호 복원'을 누릅니다.

정상 결과: 만료를 기다리지 않고 기존 보호 규칙이 다시 적용됩니다.

============================================================
STEP 12. 재시작과 링크 유지 시험
============================================================

1. 현재 외부 접속 주소 전체를 휴대폰 즐겨찾기에 저장합니다.
2. PC에서 스마트폰 연결을 중지합니다.
3. 필요한 경우 PFX 비밀번호를 다시 입력하고 연결을 시작합니다.
4. 휴대폰에서 같은 즐겨찾기로 접속합니다.
5. 다시 로그인합니다.
6. PC와 휴대폰에서 저장한 사이트 규칙이 유지되는지 확인합니다.

정상 결과:
- 접속 링크가 유지됩니다.
- 사이트 설정이 유지됩니다.
- 로그인은 다시 해야 합니다.

주의:
앱을 완전히 종료했다가 실행해도 스마트폰 연결 서버는 직접 다시
시작해야 합니다. 앱 자동 실행만으로 외부 연결까지 자동 시작하지 않습니다.
PFX 비밀번호는 프로그램 설정에 저장하지 않습니다.

============================================================
STEP 13. 시험 마무리
============================================================

1. 시험용으로 추가한 example.com 규칙을 삭제합니다.
2. 전체 일시 허용을 종료합니다.
3. 시험을 위해 변경한 PC 절전 설정을 원래대로 돌려놓습니다.
4. 외부 제어를 계속 사용할 경우 스마트폰 연결 서버를 실행해 둡니다.
5. 시험만 종료하려면 '스마트폰 연결 중지'를 누릅니다.
6. 인증서 발급에만 사용한 80번 전달·방화벽 규칙은 향후 갱신 방식에
   맞춰 정리합니다. 제거하면 HTTP 방식 갱신 때 다시 필요합니다.

============================================================
문제 발생 시 확인 순서
============================================================

증상: 같은 Wi-Fi에서도 접속 불가
확인: 선택한 PC IP, 개인 네트워크 프로필,
      게스트 Wi-Fi 및 기기 간 통신 차단

증상: PC에서 외부 연결 시작 실패
확인: 인증서 파일, PFX 비밀번호, 도메인 일치, 유효 기간,
      Windows 관리자 권한, 47831 포트 충돌

증상: LTE·5G에서 연결 시간 초과
확인: DDNS IP, 공인 WAN IP, 포트포워딩 대상 IP와 포트,
      Windows 네트워크 프로필, PC 절전 상태

증상: 외부 접속 시 인증서 경고
확인: 인증서 대상 주소, 인증기관 신뢰, 인증서 체인, 만료 여부

증상: 403 응답
확인: 등록한 외부 도메인·포트와 실제 접속 주소가 같은지 확인
      외부 모드에서는 내부 IP 주소로 접속하지 않습니다.

증상: 404 응답
확인: 주소 끝의 긴 접속 문자열까지 포함했는지 확인
      링크를 재발급했다면 이전 링크는 사용할 수 없습니다.

증상: 로그인 실패
확인: Safe Child 관리자 비밀번호인지 확인
      PFX 비밀번호나 마스터 비밀번호는 외부 로그인에 사용하지 않습니다.

증상: 인증 요청이 많다는 안내
확인: 1분 후 재시도

증상: 로그인되지만 차단되지 않음
확인: 전체 일시 허용 상태, 차단 선택, PC 시각, 적용 오류 메시지

증상: 화면은 차단인데 사이트가 계속 열림
확인: PC 브라우저를 완전히 종료하고 재접속한 뒤 실제 차단 상태 확인

참고:
일부 공유기는 같은 집 Wi-Fi에서 공인 주소로 돌아오는 접속을
지원하지 않습니다. 외부 모드 시험은 LTE·5G에서 진행하세요.
