# 회의록 저장

회의 화면 상단에서 **Word (.docx), PDF (.pdf), 텍스트 (.txt)** 중 하나를 선택하고 **회의록 저장**을 누릅니다. 처음 선택되는 형식은 Word입니다.

기본 파일은 **전체 대화 및 기록**입니다. 발언 시각, 발언자, 기록 종류를 표시하고 시간순으로 저장합니다. 화면에는 최근 200건만 보여도 파일에는 해당 방의 DB에 저장된 전체 기록이 들어갑니다. 자동 기록을 끈 동안의 음성이나 인식에 실패한 음성은 복원하지 못합니다.

**회의록 요약 추가**는 기본적으로 꺼져 있습니다. 체크하면 같은 파일 앞부분에 다음 항목을 추가하며 전체 대화는 그대로 유지합니다.

- 주요 주제와 내용: 전체 발언에서 반복되는 키워드를 기준으로 최대 6개 주제를 묶고 주제별 최대 3개 대표 발언을 발췌합니다. 출처 발언자와 시각을 함께 표시합니다.
- 확정 결정: 방장이 결정으로 기록한 항목입니다.
- 실행 항목: 방장이 실행 항목으로 기록한 내용입니다. 담당자와 기한을 입력했다면 그대로 포함됩니다.
- 추가 메모: 방장이 기록한 메모입니다.

요약은 서버에서 실행하는 키워드 기반 발췌 방식입니다. 외부 AI API에 대화를 전송하지 않고 별도 대형 모델도 실행하지 않습니다. 원문에 없는 결론·담당자·기한을 만들어내지 않습니다. 모든 논점이 요약에 포함되는 것은 아니며 전사 오류나 발췌에 따른 맥락 누락은 전체 기록에서 확인해야 합니다.

Whisper 처리 중이면 자동 기록을 끄고 대기 0건을 확인한 다음 저장하세요. 파일의 시각은 한국 시간(KST)입니다. PDF에는 한글 글꼴이 포함되며, 텍스트는 UTF-8 BOM 형식입니다. Word는 편집 가능한 DOCX 형식입니다.

## 기존 Ubuntu 서버 적용

현재 버전은 새 회의 생성에 Master 승인이 필요합니다. 업데이트 전 [SMTP 설정](MASTER_APPROVAL.md)을 함께 준비하세요.

회의가 없는 시간에 기존 다운로드 폴더의 `WebConference/RelayServer`에서 실행합니다.

```bash
git pull --ff-only
sudo bash deploy/native/install.sh /opt/moa/python/3.12.15/bin/python3.12
```

설치 스크립트가 Word·PDF 라이브러리를 설치하고 한글 글꼴을 포함한 새 릴리스를 적용한 후 `moa`를 재시작합니다. `/etc/moa/moa.env`의 `SPEECH_ENGINE=whisper` 설정은 유지되며 해당 설정이 있으면 Whisper 의존성도 설치합니다. 기존 Nginx·인증서·다른 서비스 설정은 바꾸지 않습니다.

브라우저를 새로고침한 뒤 각 형식으로 한 번씩 저장하고, 요약 체크 전후를 비교하세요.

## API

`GET /api/rooms/{room_id}/minutes?format=docx|pdf|txt&summary=true|false`

방 참여자 토큰을 `Authorization: Bearer ...`로 전달해야 합니다. 기본 API 형식은 `txt`, 요약은 `false`입니다. 인식 대기가 있으면 409, 지원하지 않는 형식은 422를 반환합니다. 예전 Markdown 다운로드는 텍스트 다운로드로 변경되었습니다.
