# Android 0.2.0: 배터리 랙 화면

- 사용자가 제공한 `배터리시스템.png`를 `drawable-nodpi/battery_rack.png`로 포함했습니다. 시작 화면과 장비 카드에서는 10개 장착 참고 사진임을 명시합니다.
- 상세 화면은 원본 사진의 상단과 모듈 구간을 Canvas에 그려 등록 모듈 1~10개를 표현합니다. 이미지를 생성하거나 실제 측정값을 가공하지 않습니다.
- 랙은 모듈 번호순이며 실제 장착 위치와는 다를 수 있습니다. 랙 또는 접근성용 가로 모듈 버튼을 누르면 해당 모듈의 SOC/SOH/전압/전류 및 셀별 전압·온도를 표시합니다. 장비 요약에는 방전 횟수, 충전 보호 차단 상태, 충전전류제한 및 장비가 지원하는 경우 SOC 충전제한도 표시합니다.
- `module_map[모듈번호].row_index`로 `module_data[측정행]`를 찾습니다. 매핑 없는 측정 행을 모듈 번호로 오인하지 않도록 별도 표기하며, 없는 측정값은 `—`로 표시합니다.
- 0개는 데이터 없음, 10개 초과는 구성 경고로 표시합니다. 초과/미매핑 측정 행도 선택 버튼에서 확인할 수 있습니다.
- 오래된 데이터는 경고하고 조회 실패 시 기존 화면을 흐리게 표시합니다. 화면 전환 중 요청이 끝나면 새 화면을 다시 조회합니다.
- 이력 API가 모듈 번호 매핑을 제공하지 않는 기존 서버에서는 이력의 식별자를 '측정 행'으로 표시합니다.
- 서버 API와 인증 설정은 그대로 사용합니다. 앱 ID와 기존 debug 서명 키를 유지하며 versionCode=2, versionName=0.2.0입니다.
- 조회용 APK에는 백그라운드 FCM 푸시가 없습니다.

검증 명령: `:app:assembleOfflineDebug :app:testOfflineDebugUnitTest :app:lintOfflineDebug`

모듈 매핑 테스트: 1개, 10개 숫자 정렬, 모듈 번호/측정 행 차이, 매핑 누락, 데이터 누락, 빈 구성, 10개 초과 데이터 보존.

실제 휴대폰에서 설치·터치·실서버 연결 확인은 별도로 필요합니다.
