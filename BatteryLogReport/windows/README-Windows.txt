축전지 로그 보고서 - Windows 64비트

실행 대상: Windows 7 SP1 / 8 / 8.1 / 10 / 11의 64비트 환경
32비트 Windows는 지원하지 않습니다.

1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. BatteryLogReport.exe를 실행합니다.
   runtime 폴더와 BatteryLogReport.jar는 EXE와 같은 폴더에 두세요.
   Java, Python, Microsoft Word를 별도로 설치하지 않아도 보고서를 생성합니다.
   생성된 DOCX를 열어 보려면 Word 등 문서 뷰어가 필요합니다.

사용 순서
- [설치장소 추가]에서 용인외사 같은 장소명을 입력합니다.
- 호기를 선택하고 [로그파일 업로드]에서 ZIP을 하나 또는 여러 개 선택합니다.
- 같은 장소·호기를 선택한 뒤 다른 종류 ZIP을 추가할 수 있습니다.
- 상단 상황창에서 장소, 호기, 파일명, 크기, 등록 상태를 확인합니다.
- [보고서 생성]을 누르고 저장할 폴더를 선택합니다.
- 선택한 폴더 아래 새 하위 폴더에 Word 보고서 2개가 저장됩니다.

생성 파일
  축전지 충·방전 로그 분석.docx
  AC 정전시 LFP에서 AC 정전을 유추.docx

식수와 파일 배정
- perfmg_minute + perfmg_uncertain 한 쌍이 축전지 1식입니다.
- 같은 종류를 여러 개 선택하면 선택한 호기부터 비어 있는 호기에 배정합니다.
- 두 종류를 각각 2개 등록하면 2식입니다.
- 파일명이 같아도 덮어쓰지 않습니다.
- 동일 내용까지 반복 등록하면 별도 호기로 등록하고 안내를 표시합니다.
- 한 종류만 제공해도 두 보고서를 생성하되 누락 항목은 확인 불가로 표시합니다.
- 장비 일련번호가 없는 CSV이므로 다른 장비의 파일은 호기별로 한 쌍씩
  등록하는 것이 가장 확실합니다. 상황창에서 장비별 짝을 확인하세요.
- 한 번에 40개, ZIP당 64 MB, 압축 해제 CSV당 128 MB까지 지원합니다.

데이터 보관
- 업로드한 원본의 사본과 등록 목록은 사용자별
  %LOCALAPPDATA%\BatteryLogReport 폴더에 저장됩니다.
- 재실행하면 이전 등록 목록을 불러옵니다.
- 로그를 추가·삭제하면 보고서를 다시 생성해야 변경 사항이 반영됩니다.
- 이전에 생성한 보고서는 덮어쓰거나 삭제하지 않습니다.
- 프로그램은 분석 중 인터넷 연결을 사용하지 않습니다.

호환성과 확인 범위
- EXE와 포함 런타임 모두 64비트입니다.
- Windows 7 SP1을 지원 대상으로 명시한 BellSoft Liberica Java 8을 포함합니다.
- Java 8 API 기준으로 컴파일하고 Windows 7에서 제공하는 실행 API를 사용합니다.
- 현재 작업 환경에서 실제 ZIP 분석과 Word 생성, 패키지 실행을 검증합니다.
- 실제 Windows 7 장비에서는 아직 검증하지 않았습니다.
- 보고서의 원본 스타일·용지·여백·테마는 보존하며 장소·수치·표·그래프를
  새 로그에 맞춰 갱신합니다. 최종 페이지의 시각적 완전 일치는 미검증입니다.
