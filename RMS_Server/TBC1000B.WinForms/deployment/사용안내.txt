TBC1000B Monitor v3.2.6 — Windows x64 고객 배포본

1. 복사하여 실행
ZIP을 모두 압축 해제한 후 폴더 전체를 쓰기 가능한 로컬 폴더에 복사합니다.
TBC1000B_Monitor_v3.2.6.exe를 실행합니다.
Assets 폴더도 반드시 함께 복사하십시오. ZIP 내부에서는 직접 실행하지 마십시오.
Program Files 등 쓰기 권한이 제한된 폴더는 피하십시오.

2. Windows 구성 요소 / 선택 설치
.NET 8.0.30 및 Windows Desktop 런타임이 실행 파일에 포함되어 있습니다.
별도 .NET, SDK, Python 또는 Excel 설치나 인터넷 연결은 필요하지 않습니다.
64비트 Windows 10/11 PC용입니다. 32비트 Windows용 배포본이 아닙니다.
처음 실행할 때 포함된 네이티브 구성 요소를 사용자 임시 폴더에 자동으로 풉니다.
사용자 임시 폴더에도 쓰기 권한이 필요합니다.
Install.cmd를 실행하면 현재 사용자 LocalAppData에 복사하고 바탕화면 바로가기를 만듭니다.
이 선택 설치는 관리자 권한이 필요하지 않습니다. 기존 설치가 있으면 덮어쓰지 않습니다.
삭제할 때는 프로그램 종료 후 설치 폴더와 바로가기를 삭제합니다. 설정/기록은 먼저 백업하십시오.

3. 최초 설정과 장비 연결
프로그램에서 현장 프로파일을 생성하고 장비 IP, 포트, community를 입력합니다.
기존 설정을 사용할 경우 프로그램 종료 후 백업한 profiles 폴더의 필요한 INI를 복사합니다.
개발 PC의 현장 설정이나 접속정보는 이 배포본에 포함하지 않았습니다.
장비 통신에는 현장 네트워크 연결이 필요합니다.
방화벽 허용 요청이 나오면 현장 정책에 따라 사용 네트워크에서 프로그램을 허용합니다.
SNMP 요청은 기본 UDP 161, Trap 수신 포트는 프로파일 설정을 확인하십시오.
Master/Slave 기능은 UDP 50000 및 51000~52000 포트가 사용됩니다.

4. 데이터 저장 / 업데이트
설정은 실행 파일 옆 profiles, 운전 기록은 Operation data record,
Trap 기록은 Trap logs 폴더에 저장됩니다. 필요한 폴더는 실행 중 자동 생성됩니다.
업데이트 전 프로그램을 종료하고 위 폴더들을 별도 백업하십시오.
새 버전은 새 폴더에 압축 해제한 후 필요한 설정만 옮기는 방식을 권장합니다.

5. 배포 정보
Release 최적화, 압축 단일 실행 파일, .NET 런타임 포함 방식입니다.
WinForms 동작 보존을 위해 코드 트리밍은 적용하지 않았습니다.
SHA256SUMS.txt는 최초 배포 파일의 무결성 확인용입니다.
이 배포본은 디지털 코드 서명이 적용되지 않았습니다.
이 프로그램은 Windows용 장비 감시/제어 프로그램입니다. 장비에 업로드하는 펌웨어 파일이 아닙니다.
