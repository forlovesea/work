# ETF·단일 종목 GUI 사용법

세 실행 파일 모두 다크 테마 GUI를 엽니다. `start.bat`는 모의매매, `start_etf.bat`는 ETF 자동 선정·주문, `start_live.bat`는 지정한 단일 종목 주문입니다.

## 실행 순서

1. 최초 `install_auto.bat`로 설치하고 원하는 실행 파일을 엽니다.
2. **인증·계좌 설정**에서 토스 인증값을 입력합니다. ETF에는 KRX·DART·네이버 인증도 입력합니다.
3. **계좌 조회**로 조회된 accountSeq를 입력합니다. 단일 종목은 종목코드도 입력합니다.
4. **암호화 저장**을 누릅니다. 같은 Windows 사용자 DPAPI 저장소를 사용하며 기존 콘솔에서 저장한 값도 불러옵니다.
5. **읽기 전용 점검**으로 계좌·분석·시세를 확인합니다. 주문을 제출하지 않는 점검이며 가상 체결 시뮬레이션은 아닙니다.
6. **중지 요청** 후 프로세스 종료를 확인합니다.
7. **실전 시작**을 누르고 실제 주문 확인창을 승인하면 자동 주문을 시작합니다. STOP 파일이 남아 있으면 기존 주문 확인 후 해제 여부를 묻습니다.

창만 열어서는 주문하지 않습니다. 한 폴더에서는 ETF·단일 종목·읽기 전용 점검 중 하나만 실행할 수 있습니다. 실전 기록이 있는 단일 종목의 코드는 GUI에서 변경하지 못합니다.

## 상태와 그래프

- 실전·읽기 전용 모드, 원금·상한·최근 상태를 표시합니다. 주문 표의 수량은 주문 수량이며 상태와 반영된 체결 수량도 표시합니다.
- 일·주·월·연·전체·직접 기간, 달력과 확대 그래프를 지원합니다. 주는 월요일부터입니다.
- 차트는 봇 관리 자산의 일별 마지막 관측값입니다. 계좌 전체 자산이나 분봉이 아닙니다.
- 카드 수익률은 설정 원금 기준, 그래프는 선택 기간 직전 관측값 기준입니다. 이전 장부에 과거 관측값이 없으면 기록 시작 시의 평가액을 기준으로 합니다. 과거 실적을 만들지 않습니다.
- 최대 낙폭 표시는 기록 기능 추가 이후 관측한 값입니다. 실전과 읽기 전용 기록은 분리됩니다.
- 장외·휴장·시세 오류 시 새 평가값이 없을 수 있으므로 상단 마지막 관측 시각을 확인하세요.

## 중지와 종료

**중지 요청**은 기존 엔진의 미체결 취소·확인을 실행하며 보유분을 매도하지 않습니다. 운용 중 창을 닫으면 중지 후 종료 여부를 묻고 동의 시 봇 종료까지 창을 유지합니다. 통신 장애로 취소가 확인되지 않으면 토스 앱에서 확인해야 합니다.

강제 종료·절전·연결 끊김 시 기존 주문이 남을 수 있습니다. 원금 3만원·1회 9천원·원화 현금 한도와 주문 결과 불명확 시 재전송 금지는 그대로입니다. 실계좌 체결·전략 수익성이 검증되었다는 뜻은 아닙니다.

기존 콘솔은 `python launch_live.py --etf` 또는 `python launch_live.py`로 사용할 수 있습니다.

## 집 인터넷·테더링 전환

IP 변경만으로 토스 API 키를 재발급할 필요는 없습니다. 기존 키를 유지하고 토스증권 웹의 **설정 → Open API → 허용 IP 관리**에서 새 공인 IP를 추가·수정합니다. 등록 가능한 개수 범위에서 집과 테더링 IP를 함께 등록할 수 있습니다. 프로그램은 허용 IP를 자동 등록하지 않습니다.

**중지 요청 → 봇 종료·토스 미체결 확인 → 네트워크 변경 → PC의 공인 IP 확인·등록 → 읽기 전용 점검 → 점검 중지 → 실전 시작** 순서로 진행합니다. 테더링뿐 아니라 집의 유동 IP도 변경될 수 있습니다. 키 자체를 재발급한 경우에만 GUI 인증·계좌 설정의 키를 갱신합니다.

근거: [토스 공식 인증 안내](https://developers.tossinvest.com/docs/auth). Word 매뉴얼의 ‘09 / 접속 환경 변경’에도 같은 절차를 정리했습니다.
