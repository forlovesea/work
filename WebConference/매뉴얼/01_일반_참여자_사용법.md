# 일반 참여자 사용법

방장이 공유한 초대 링크 또는 서버 주소와 방 접속 ID로 입장하는 사람을 위한 안내입니다. 별도의 Python 설치는 필요하지 않습니다.

## 초대 링크로 빠르게 참여하기

1. 방장이 보낸 초대 링크를 Chrome 또는 Edge에서 엽니다. 예: `https://meet.example.com/#room=4AB891762964`.
2. **초대 링크로 접속했습니다** 안내와 자동 입력된 서버 주소·방 접속 ID를 확인합니다. 이전에 저장한 서버 주소가 있어도 초대 링크의 서버를 사용합니다.
3. **내 이름**을 입력하거나 저장된 이름을 확인합니다.
4. 마이크·스피커·카메라를 사용할지 선택합니다. 기본값은 모두 꺼짐이며 링크를 여는 것만으로 입장하거나 장치를 켜지 않습니다.
5. **회의 참여하기**를 누릅니다. 입장 후 상대방 소리를 들으려면 스피커를 켜세요.

링크의 ID가 올바르지 않다는 안내가 나오면 방장에게 전체 링크를 다시 받으세요. 종료된 방은 기존 링크로 들어갈 수 없으므로 새 방의 링크를 받아야 합니다. 링크 없이 서버 주소와 접속 ID를 받은 경우에는 아래 절차를 따릅니다.

## 1 접속 전에 준비하기

1. 방장에게 **중계 서버 주소**와 **방 접속 ID**를 받습니다.
2. PC에서 Chrome 또는 Edge를 엽니다. 화면 공유는 데스크톱 브라우저를 기준으로 설명합니다.
3. 헤드셋 또는 이어폰을 연결합니다. 마이크가 있는지 확인합니다.
4. 다른 화상회의 앱이 카메라·마이크를 사용 중이면 정리합니다.
5. 주소창에 방장이 알려준 주소를 입력합니다. 예: `https://meet.example.com`.

브라우저의 장치 권한과 프로그램의 장치 버튼은 별개입니다. 브라우저에서 마이크 사용을 허용했더라도 프로그램의 마이크가 꺼져 있으면 음성이 전달되지 않습니다.

## 2 접속 설정 입력하기

| 항목 | 입력과 확인 방법 |
| --- | --- |
| 중계 서버 주소 | 관리자에게 받은 `https://호스트` 또는 `https://호스트:포트` 입력. `/api` 같은 경로는 넣지 않음 |
| 연결 확인 | 누른 뒤 `연결됨 · 한 방 최대 …명` 표시 확인 |
| 내 이름 | 다른 참석자가 알아볼 표시 이름 입력. 최대 40자 |
| 마이크 | 기본 꺼짐. 입장 후 직접 켜도 됨 |
| 스피커 | 기본 꺼짐. 상대방 소리를 들으려면 입장 전이나 입장 후 켜야 함 |
| 카메라 | 기본 꺼짐. 사용하려면 켜고 브라우저 권한 허용 |
| 방 접속 ID | 방장이 공유한 코드 입력. 영문 대소문자·하이픈·공백은 서버가 정리해 비교 |

서버 주소를 바꿨다면 **연결 확인**을 다시 누르세요. HTTPS로 열린 화면에서 HTTP 서버로 연결하려 하면 브라우저 보안 정책으로 연결할 수 없습니다.

## 3 방에 들어가기

1. **회의 참여** 탭을 선택합니다.
2. **내 이름**을 입력합니다.
3. **방 접속 ID**를 입력합니다.
4. 입장할 때 사용할 마이크·스피커·카메라를 선택합니다. 모두 꺼 둔 상태로도 입장할 수 있습니다.
5. **회의 참여하기**를 누릅니다.
6. 카메라나 마이크 권한 창이 나오면 사용하려는 장치에 대해 허용합니다.
7. 방 이름과 참석자 목록에 본인 이름이 표시되는지 확인합니다.
8. 상대방 말을 들으려면 하단 **스피커 꺼짐**을 눌러 **스피커 켜짐**으로 바꿉니다.

입장 직후 자신의 이름만 보인다면 다른 참석자가 아직 들어오지 않았을 수 있습니다. 참석자는 보이지만 영상·음성이 계속 연결되지 않으면 관리자에게 네트워크 점검을 요청하세요.

## 4 듣기와 말하기

### 4.1 버튼 상태 이해하기

| 표시 | 의미 | 해야 할 일 |
| --- | --- | --- |
| 마이크 꺼짐 | 내 마이크를 사용하지 않음 | 말하려면 클릭해 켜기 |
| 마이크 켜짐 | 발언 가능한 상태로 내 음성 전송 | 말을 마치면 필요에 따라 끄기 |
| 마이크 대기 | 마이크는 선택했지만 회의 모드에서 발표권이 없음 | 손을 들고 방장에게 발표권 요청 |
| 스피커 꺼짐 | 다른 사람의 음성을 재생하지 않음 | 듣기 위해 켜기 |
| 카메라 꺼짐 | 카메라 영상 대신 이름 아바타 표시 | 영상이 필요할 때 켜기 |

마이크와 스피커는 서로 독립적입니다. 마이크만 켜면 내 말은 전달돼도 상대방의 말은 들리지 않을 수 있습니다.

### 4.2 FREE Talk에서 말하기

1. **스피커**를 켭니다.
2. **마이크**를 켭니다.
3. 다른 참석자들과 자유롭게 이야기합니다.
4. 여러 사람이 동시에 말할 수 있으므로 필요하지 않을 때는 마이크를 끕니다.

FREE Talk에서는 발언을 위해 발표권을 받을 필요가 없습니다. 다만 화면 공유와 화이트보드 그리기는 여전히 발표자 권한이 필요합니다.

### 4.3 회의 모드에서 말하기

1. 하단의 **손들기**를 누릅니다.
2. 버튼이 **손 내리기**로 바뀌고, 방장의 참석자 목록에 발언 요청이 표시됩니다.
3. 방장이 본인을 **발표 지정**할 때까지 기다립니다.
4. 본인이 발표자라는 안내를 확인합니다.
5. 마이크가 꺼져 있으면 직접 켭니다. 발표권을 받아도 마이크가 자동으로 켜지지는 않습니다.
6. 발표권이 다른 사람에게 넘어가면 본인의 음성이 서버에서 차단되고, 켜 둔 마이크는 대기 상태가 됩니다.

발표권은 한 명에게만 지정됩니다. 자동 회의록 옵션이 꺼져 있어도 회의 모드는 한 사람씩 발표합니다. 자동 순번 배정 기능은 없고 방장이 발표 순서를 정합니다.

## 5 회의 화면 바꾸기

| 버튼 | 표시 내용 | 사용 예 |
| --- | --- | --- |
| 다중 화면 | 모든 참석자를 타일로 표시 | 표정과 참여 상태 확인 |
| 발표자 | 현재 발표자의 카메라 또는 공유 화면을 크게 표시 | 발표·문서 설명 보기 |
| 화이트보드 | 방에서 공유하는 그림판 표시 | 설명 도식 보기 |
| 화면 오른쪽의 전체 화면 아이콘 | 현재 선택한 회의 화면 확대 | 작은 글씨나 그림 보기 |

화면 배치는 **본인의 화면에만 적용**됩니다. 내가 화이트보드로 바꿨다고 다른 사람도 자동으로 바뀌지 않습니다. 발표자가 화면을 공유하면 각자 **발표자** 탭을 선택해 크게 보세요. 전체 화면은 `Esc`로 나올 수 있습니다.

카메라가 꺼진 참석자는 영상 대신 이름의 첫 글자가 표시됩니다. 화면을 어떤 탭으로 바꾸더라도 스피커를 켜 두었다면 참석자의 음성은 계속 들립니다.

## 6 발표자로 지정됐을 때 화면과 파일 공유하기

### 6.1 열린 파일 함께 보기

1. 발표할 PDF, 문서, 스프레드시트, 슬라이드 또는 이미지를 PC에서 먼저 엽니다.
2. 방장에게 발표자로 지정해 달라고 요청합니다.
3. 하단 **화면·파일 공유**를 누릅니다.
4. 브라우저 선택 창에서 공유할 **창**, **탭** 또는 **전체 화면**을 선택합니다.
5. 공유를 시작하고 참석자에게 **발표자** 탭을 선택해 달라고 안내합니다.
6. 파일을 넘기거나 스크롤하면서 설명합니다.
7. 설명이 끝나면 **공유 중지** 또는 브라우저의 공유 중지 버튼을 누릅니다.

공유 중에는 본인의 카메라 영상 자리에 공유 화면이 전송됩니다. 카메라와 화면을 동시에 두 개의 영상으로 전송하지 않습니다. 공유를 멈추면 켜 둔 카메라로 돌아가고, 카메라가 꺼져 있으면 아바타로 돌아갑니다.

이 기능은 파일을 서버에 업로드하지 않습니다. 다른 참석자가 파일을 다운로드하거나 함께 수정하는 기능은 없습니다. 동영상이나 음악의 시스템 소리는 공유하지 않으며 발표자의 마이크로 설명합니다. 공유할 창에 표시되는 내용은 참석자가 볼 수 있으니 공유 대상을 선택할 때 확인하세요.

### 6.2 화이트보드 사용하기

1. **화이트보드** 탭을 선택합니다.
2. 본인이 현재 발표자인지 확인합니다.
3. 펜 색과 두께를 선택합니다.
4. 마우스를 누른 채 움직이거나 터치로 그립니다.
5. 참석자는 자신의 화이트보드 탭에서 내용을 봅니다.

**지우기**는 보드 전체를 지웁니다. 실행 취소나 부분 지우개는 없습니다. 지운 내용은 되돌릴 수 없으므로 함께 보고 있는 사람이 내용을 확인했는지 먼저 확인하세요. 화이트보드 저장·내보내기 버튼도 없으므로 필요한 그림은 회의 중 OS 화면 캡처로 보관합니다.

늦게 입장한 사람도 현재 방의 그림을 받습니다. 그러나 마지막 사람이 나가거나 서버가 재시작되면 보드는 사라집니다.

## 7 회의록 보기와 저장하기

1. 오른쪽 **회의록** 탭을 누릅니다.
2. **음성 인식 기록 중** 또는 **자동 기록 꺼짐** 표시를 확인합니다.
3. 자동 기록 중이면 발표자의 발언이 문장 단위로 잠시 뒤 표시됩니다.
4. 방장이 추가한 **확정 결정**, **실행 항목**, **추가 메모**를 확인합니다.
5. 상단 **회의록 저장**을 누릅니다.
6. 브라우저 다운로드 폴더에서 `회의록-접속ID.md` 파일을 확인합니다.

일반 참여자도 자기 방의 회의록을 다운로드할 수 있습니다. 일반 참여자는 기록을 추가·수정하거나 자동 기록 옵션을 바꿀 수 없습니다. 전사 오류가 있으면 방장에게 정정 메모를 남겨 달라고 요청하세요.

화면에는 최근 200개 기록이 표시되며 다운로드 파일에는 그 시점까지 DB에 저장된 전체 기록이 들어갑니다. 마지막 발언은 인식 완료까지 시간이 걸릴 수 있으므로 발언을 마친 뒤 기록이 표시됐는지 확인하고 저장하세요. 저장 파일의 시간은 UTC이며 한국 시간은 UTC보다 9시간 빠릅니다. 화면의 시간은 브라우저 현지 시간으로 표시됩니다.

## 8 나가기와 다시 입장하기

1. 필요한 회의록을 먼저 저장합니다.
2. 하단 **나가기**를 누릅니다.
3. 접속 설정 화면으로 돌아왔는지 확인합니다.

같은 방에 다른 사람이 남아 있다면 동일한 접속 ID로 다시 들어갈 수 있습니다. 새로고침이나 브라우저 종료도 연결을 끊을 수 있으며, 자동 재입장 기능은 없습니다. 재입장 시 마이크·스피커·카메라는 다시 확인하세요.

**마지막 사람이 나가면 방이 종료**됩니다. 종료된 접속 ID는 다시 사용할 수 없으며 방장이 새 방을 만들어야 합니다. 혼자 있는 방에서 새로고침해도 기존 방이 종료될 수 있습니다.

## 9 참여자 문제 해결

| 증상 | 먼저 확인할 항목 | 다음 조치 |
| --- | --- | --- |
| 소리가 전혀 안 들림 | 스피커 버튼 꺼짐, OS 음량, 브라우저 탭 음소거, 출력 장치 | 스피커 버튼을 껐다 켜고 상대방 마이크·발표권 확인 |
| 상대방이 내 말을 못 들음 | 내 마이크, 브라우저 권한, 회의 모드 발표권 | 마이크 대기면 방장에게 발표권 요청 |
| 마이크·카메라 요청 창이 안 뜸 | 주소가 HTTPS 또는 localhost인지 | 주소 표시줄의 사이트 권한에서 허용 후 재입장 |
| 방 접속 ID 오류 | ID 오타, 서버 주소, 종료된 방 여부 | 방장에게 현재 접속 정보를 다시 받기 |
| 최대 인원 오류 | 기본 8명 제한, 접속 대기 예약 | 중복 탭 종료 후 잠시 기다리기. 실패한 입장 예약은 약 2분 뒤 정리 |
| 화면 공유 버튼이 비활성 | 본인이 현재 발표자인지 | 발표권 요청 |
| 공유 화면이 작게 보임 | 다중 화면 탭을 보고 있는지 | 발표자 탭과 전체 화면 사용 |
| 화이트보드에 그릴 수 없음 | 발표자 권한 | 발표권 요청 |
| 울림·하울링 | 같은 장소의 여러 장치에서 스피커와 마이크를 켰는지 | 헤드셋 사용 또는 불필요한 장치 끄기 |
| 참석자만 표시되고 영상이 계속 멈춤 | 본인·상대방 카메라 상태 | 관리자에게 WebRTC UDP·TURN 연결 점검 요청 |
| 연결이 끊어짐 | 서버와 네트워크 상태 | 같은 방이 살아 있으면 재입장, 종료됐으면 새 ID 받기 |
