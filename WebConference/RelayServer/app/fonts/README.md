# PDF Korean fonts

Unmodified Nanum Gothic Regular and Bold from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/nanumgothic

Copyright NHN Corporation. Distributed under the SIL Open Font License 1.1;
see OFL.txt. The PDF exporter embeds font subsets so clients do not need to
install Korean fonts. Word documents use Malgun Gothic with reader font fallback.
