# 충방전 이벤트 기록

WinForms v3.2.13과 동일한 기본 설정과 이벤트 판정을 적용했습니다.

- 장비의 전체 SNMP 수집 주기가 완료되면 Excel 운전 기록과 독립적으로 자동 감시합니다. 초기 화면 표시용 부분 데이터는 사용하지 않습니다.
- 방전: 총용량(Ah)의 50%에 해당하는 전류(A), 5분 간격. 설정 범위 1~90%.
- 충전: 기본 50A, 10분 간격. 최초 유효 데이터에서 `min(50A, 총용량 × 충전전류제한(C))`로 초기화합니다. 직접 적용한 설정은 자동 변경하지 않습니다.
- 양수 전류는 충전, 음수는 방전입니다. 임계값 이상에서 시작하고, 임계값 아래에서도 유지하며, 0A 또는 방향 전환에서 종료합니다.
- 간격은 5/10/15/20/25/30분입니다. 도래 후 첫 유효 측정값으로 기록하며 누락 구간을 보간하지 않습니다.
- 통신 실패, 필수값 누락, 설정 변경, 연결 종료, 프로그램 종료는 마지막 유효 측정값과 함께 `중단 · 종료시각 미확정`으로 기록합니다.
- 기록 설정창 하단에서 충전/방전을 개별 선택하고 `설정 변경 적용` 또는 `이벤트 기록시작`, `이벤트 기록중지`를 사용합니다. 설정창을 닫아도 감시는 계속됩니다. 중지 상태에서 설정 변경만으로 재개되지 않습니다. 앱을 다시 실행하면 기본값으로 시작합니다.
- 충전 상한을 확인하지 못했거나 현재 설정이 상한을 초과하면 충전 감시를 보류합니다. 설정 적용 시 최신 측정값과 상한을 다시 검증합니다. 장비의 충전제한 설정 자체는 변경하지 않습니다.
- 저장 위치: 실행 스크립트(패키징 시 EXE) 옆 `Operation data record/충방전 이벤트 기록.csv`. UTF-8 BOM CSV이며 기존 운전 Excel 파일과 별도입니다.
- 이벤트ID, 시스템, 종류, 기록구분, 기록·측정·시작시각, 전류, SOC, 총용량, 시작임계전류, 간격, 사유를 누적 기록합니다. 쓰기 실패/파일 잠금 오류 시 알림 후 이벤트 감시를 중지합니다.

`charge_discharge_record.py`를 실행 스크립트와 같은 폴더에 함께 보관하세요. PyInstaller는 정적 import를 통해 이 모듈을 포함합니다. 기존 배포 EXE에는 소스 변경이 자동 반영되지 않으므로 별도 재빌드가 필요합니다.

검증: 이벤트 상태·CSV·오류 처리 테스트 10개, 두 프로그램 설정창 및 수집 결과 연결 테스트 통과. 실제 장비 연결 시험과 EXE 재빌드는 수행하지 않았습니다.
