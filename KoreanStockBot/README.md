# 국내 주식 전략 실험실

**EXE 배포:** `Release/KoreanStockBot/KoreanStockBotETF.exe`(ETF), `KoreanStockBotStock.exe`(단일 종목), `KoreanStockBotPaper.exe`(모의).
`_internal`과 작업 EXE를 포함한 폴더 전체가 필요합니다. 빌드·검증은 [EXE_BUILD_GUIDE.md](EXE_BUILD_GUIDE.md)를 참고하세요.

**실전 GUI 연결:** `start_etf.bat`와 `start_live.bat`도 다크 테마 GUI를 엽니다.
인증·계좌 설정 → 읽기 전용 점검 → 실전 시작 버튼을 사용하세요.
기간별 그래프·달력·중지 방법은 [GUI_GUIDE.md](GUI_GUIDE.md)를 확인하세요.

**코스닥 관련 ETF 순자산 상위 최대 20개 전략:** [ETF_GUIDE.md](ETF_GUIDE.md)를 확인하세요.
최초 `install_auto.bat` 실행 후 `start_etf.bat`로 시작합니다. CSV나 종목 목록을 준비할 필요가 없습니다.
ETF별 편입 기업 재무정보와 뉴스 규칙을 반영하며, 비용을 고려한 10% 익절 목표를 사용합니다.
KRX 순자산·편입 종목, DART 재무제표, 네이버 뉴스를 자동 수집하고 주기적으로 갱신합니다.
최초 토스/KRX/DART/네이버 인증 설정은 필요합니다. Windows 암호화 저장을 선택하면 다음 실행부터 재사용합니다.
실제 인증을 통한 최신 자료 수집과 계좌 주문 검증은 아직 수행하지 않았습니다.

Python 3.10 이상을 사용합니다. 자동 수집은 `requirements.txt`의 pykrx가 필요하며, 시작 자금 기본값은 30,000원입니다.
**오프라인 백테스트/모의 재생**과 **토스증권 실전 자동주문**을 지원합니다.
`start.bat`는 모의매매 화면이며 실전 GUI의 시작 버튼은 별도 실제 주문 확인을 거칩니다.
기존 콘솔은 `python launch_live.py`로 열며 `LIVE`를 입력하면 실제 주문을 시작합니다.
실전 설정·중지·복구 방법은 먼저 [LIVE_GUIDE.md](LIVE_GUIDE.md)를 읽으세요.
실계좌 접속·체결 검증은 아직 수행하지 않았습니다. `toss_readonly.py`는 인증/종목정보 조회만 확인합니다.

## 실행

이 폴더의 `start.bat`를 더블클릭하거나 PowerShell에서:

```powershell
cd C:\Users\Administrator\Downloads\proj\GITHUB\work\KoreanStockBot
python app.py
python app.py --demo
python app.py --csv .\my_stock.csv
python -m unittest -v
```

화면에서 CSV 불러오기 → 백테스트 또는 모의 재생 → 결과 저장 순서로 사용합니다.
재생은 과거 일봉을 빠르게 순회하는 가상 거래입니다. 중지 후 재실행은 원금부터 초기화합니다.
결과 저장 시 체결 내역, 평가자산, 일/ISO 주/월 수익률 및 화면 설정을 `reports`에 기록합니다.
CLI의 기본 출력 디렉토리는 덮어쓰므로 보존할 때는 `--output reports/실험이름`을 지정하세요.

## 입력 데이터

CSV는 한 종목의 일봉이며 UTF-8, 날짜 오름차순, 날짜 중복 없이 다음 열을 사용합니다.

```csv
date,open,high,low,close,volume
2025-01-02,3000,3100,2950,3050,120000
2025-01-03,3050,3080,2990,3010,100000
```

화면에는 최소 21봉이 필요합니다. 분할/배당 등 기업행사를 일관되게 반영한 데이터를 사용하세요.
내장 252봉은 **합성 데이터**이며 실제 종목, 휴장일, 호가단위를 재현하지 않습니다.
합성 데이터 수익률은 투자 성과의 증거가 아닙니다.

## 전략과 한계

- 직전 종가 기준 5일 평균이 20일 평균보다 높으면 진입, 낮으면 청산 신호입니다.
- 종가 기준 손절 3%, 익절 6%; 신호 다음 거래일 시가에 슬리피지를 적용합니다.
- 기본 투자비중 30%, 현금 내 정수 주식만 매수하고 신용/레버리지를 사용하지 않습니다.
- 수익과 손실은 다음 거래의 투자 가능 금액에 반영됩니다.
- 평가자산의 고점 대비 낙폭 10% 도달 시 신규 진입 중단 후 다음 거래 가능한 봉에서 청산합니다.
- 손절/낙폭은 손실 상한 보장이 아닙니다. 갭 하락과 거래정지로 더 큰 손실이 가능합니다.
- 수수료 0.015%, 매도세 0.2%, 슬리피지 0.1%는 **실험용 가정**입니다. 현재 계좌와 상품의 실제 요율을 확인해 바꾸세요.
- 거래량 0에서는 체결하지 않습니다. 호가 잔량, 부분체결, 가격제한, 결제일과 실제 세금 반올림은 모델링하지 않습니다.
- 최종 평가액은 미청산 주식을 종가로 평가하며 향후 청산 비용은 차감하지 않습니다.
- 기간 수익률은 해당 기간 직전 평가액 대비 마지막 평가액이며 첫/마지막 주·월은 부분 기간일 수 있습니다.
- 합성 데이터 및 한 종목에서 좋은 결과가 나와도 실전 수익을 의미하지 않습니다. 별도 검증기간과 다양한 시장 구간이 필요합니다.

## 10% 복리 목표

하루, 일주일, 한 달마다 각각 10%를 얻는 것은 서로 다른 시나리오입니다.
GUI의 계산기는 252거래일/52주/12개월 동안 매번 10%를 얻었다는 **산술 가정**만 보여줍니다.
월 10%만 해도 1년에 원금 약 3.14배입니다. 지속적인 달성을 약속할 수 없습니다.
목표를 맞추려고 무리하게 거래하거나 손실 후 투자 비중을 늘리는 기능은 없습니다.

## 토스증권 Open API 신청

공식 시작 안내 확인일: 2026-10-11.

1. [토스증권 공식 Open API 안내](https://home.tossinvest.com/ko/open-api)에서 서비스 내용을 확인합니다.
2. 토스증권 웹(WTS)에 본인 계정으로 로그인하고 **설정 → Open API**로 이동합니다.
3. 안내에 따라 서비스를 등록하고 `client_id`, `client_secret`을 발급받습니다.
4. 같은 화면의 **허용 IP 관리**에서 이 프로그램을 실행할 네트워크의 공인 IP를 등록합니다. IP 변경 시 갱신이 필요합니다.
5. 키는 채팅/스크린샷/소스코드/Git에 넣지 않습니다. 로컬 환경변수 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`으로 설정한 뒤 새 터미널에서 `python toss_readonly.py`를 실행합니다.
6. 성공 시 인증/종목정보 조회 성공 문구만 표시하며 토큰이나 계좌정보를 출력하지 않습니다.

메뉴가 보이지 않으면 공식 안내/고객센터에서 본인 계정의 이용 가능 여부를 확인하세요.
계좌·자산·주문 API에는 OAuth 토큰 외에 `X-Tossinvest-Account` 계좌 헤더가 필요합니다.
실전 모듈은 주문 식별자/중복 방지, 재시작 시 미체결 조회, 부분체결 반영,
정규장·휴장일 확인, 잔고·매수가능금액 확인, 중지 파일과 미체결 취소를 구현했습니다.
동작 조건과 검증 한계는 [실전 안내](LIVE_GUIDE.md)를 참고하세요.
