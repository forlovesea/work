# 검증 기록

## Windows x64

- 64비트 네이티브 EXE 및 Liberica Java 8 x64 포함 패키지 빌드 성공.
- EXE의 PE machine = AMD64, PE32+, 최소 subsystem = 6.1 확인.
- 포함 javaw.exe 및 jvm.dll의 AMD64/PE32+ 및 subsystem 6.0 확인.
- 실제 네이티브 EXE를 통해 실행한 Windows 패키지 검증 97개 통과.
- 같은 포함 Java 8 런타임에서 공통 분석·문서 무결성 검증 114개 통과.
- 단일 업로드 후 같은 호기에 추가 업로드, 동일 파일명/동일 내용의 2식 처리, 복수 설치장소, 등록 복원, 잘못된 ZIP 거절, 기존 보고서 보존, 특수문자 장소명, Word 서식 파트 보존 검증.
- 실행 검증 환경: Java 1.8.0_513-b07 / amd64 / Windows 10 10.0 (JVM 보고값).
- 최종 Swing 화면을 렌더링하여 한국어 표시, 상황창 표 헤더, 파일명·크기, 버튼 및 카드 정렬을 시각 확인함. 실제 파일 선택 대화상자 조작 자동화는 수행하지 않았으며 업로드·저장 로직은 패키지 검증으로 확인함.
- Windows 7 SP1 이상 x64를 대상으로 빌드했으나 실제 Windows 7 실기기는 미검증.

## Android 및 문서

- Release APK 빌드 성공. Android 8.0(API 26) 이상, target API 35.
- APK Signature Scheme v2 서명 검증 통과.
- 실제 로그 및 경계 사례 114개 검증 통과.
- 실제 샘플: 방전 최저 -102.3 A, 충전 최고 +106.0 A, SOC 90~100%, 방전 중 부하 4,730~5,020 W.
- SOC 회복: 2026-09-29 10:05:00.
- 방전 상태: 08:15:53, Battery 공급: 08:15:56, 이후 Unknown: 08:57:34.
- 1식 보고서에 예시 2호의 숫자·이미지·작성일이 남지 않는지 검사.
- 복수 장소, 3식 이상 표 분리, 특수문자 장소명, 무방전, 미회복, 반복 방전, 기록 공백, 결측 및 잘못된 단위, 충돌 기록 검사.
- 생성 DOCX의 참조 이미지 존재 및 보존 대상 OOXML 파트 바이트 일치 검사.
- 연결된 Android 실기기·에뮬레이터가 없어 실제 기기의 파일 선택·저장·공유 동작은 실행 검증하지 못함.
- 기본 문서 렌더러는 이 Windows 런타임에 LibreOffice가 포함되어 있지 않아 실행 불가. 설치된 Word의 자동 PDF 출력도 응답하지 않아 중단함. 따라서 최종 Word 페이지의 시각 검증 및 원본과의 완전한 화면 일치는 아직 확인하지 못함.
