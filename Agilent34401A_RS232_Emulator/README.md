# Agilent 34401A 실시간 전압 측정 프로그램

Windows 10에서 Agilent 34401A의 RS-232 연결을 통해 DC 전압을 읽고, 실시간 그래프와 CSV/Excel 저장을 제공합니다.

## 실행 파일 만들기

이 폴더에서 `build.bat`을 실행합니다.

완료되면 `Release\Agilent34401A_v1.0.0.2.exe` 단일 실행 파일이 만들어집니다. 대상 Windows PC에는 Python이나 별도 패키지를 설치하지 않아도 됩니다. 빌드 PC에서는 처음 빌드할 때 Python 3과 인터넷 연결이 필요합니다.

실행 파일과 프로그램 창에는 Agilent 34401A 아이콘이 적용됩니다.
프로그램 제목 표시줄에는 버전 `v1.0.0.2`와 릴리스 날짜 `2026-11-26`가 표시됩니다.

## 사용 방법

1. PC와 34401A를 RS-232 케이블로 연결하고 계측기 전원을 켭니다.
2. 프로그램에서 COM 포트, 통신 속도, 흐름 제어, 패리티를 계측기 설정과 동일하게 지정합니다. 이전에 확인한 장비 설정에 맞춰 패리티는 짝수를 사용합니다.
3. **COM 연결**을 눌러 포트를 연결합니다. 연결 중에는 포트와 통신 설정이 잠기며, **COM 연결 해제**를 누르면 측정/오류 조회를 중지하고 포트를 놓습니다. 프로그램을 종료할 때도 연결을 해제합니다.
4. 측정 간격의 Hour(0~24), Min(0~60), ms(0~30000)를 설정하고 **측정 시작**을 누릅니다. 기본 측정 간격은 0시간, 0분, 1000 ms이며 전체 간격은 각 단위의 합으로 계산합니다. 세 값을 모두 0으로 설정할 수는 없습니다. 응답 대기 시간은 3, 5, 10, 20초 중 선택하며 기본값은 10초입니다.
5. 화면 아래 **RS-232 송수신 원시 데이터 (TX/RX)**에서 `MEAS:VOLT:DC?` 송신 명령과 계측기 응답의 ASCII 및 16진수 바이트를 확인합니다.
6. 원시 로그에서 마우스로 복사할 내용을 선택한 후 **선택 복사**를 누르거나, **전체 복사**를 눌러 클립보드에 복사합니다. 로그에서 우클릭해 복사할 수도 있습니다.
7. 측정을 중지한 뒤 **SYST:ERR? 오류 조회**를 눌러 계측기 오류 큐를 확인합니다. 오류 조회는 `SYST:REM`을 보내지 않고 `SYST:ERR?`만 전송합니다. 이 명령은 큐의 가장 오래된 항목을 읽고 제거합니다.
8. 측정 중 또는 중지 후 **CSV 저장**이나 **Excel 저장**을 눌러 데이터를 저장합니다.

COM 연결에 실패하면 다른 프로그램 인스턴스가 해당 포트를 사용 중일 수 있습니다. 이 프로그램은 다른 프로세스가 점유한 포트를 강제로 해제할 수 없으므로, 포트를 연 이전 인스턴스에서 연결을 해제하거나 프로그램을 종료하세요.

통신 속도는 300, 600, 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200 baud 중에서 선택할 수 있습니다. PC와 계측기의 baud rate 및 흐름 제어 설정이 일치해야 합니다. 계측기가 해당 통신 속도를 지원하는지 확인하세요. 그래프의 가로 스크롤바로 이전 측정 구간을 탐색할 수 있고, 측정점에 마우스를 올리면 시각과 전압이 표시됩니다. 그래프 위에서 휠을 올리거나 내리면 시간축을 확대·축소하며, 전압축도 현재 보이는 구간에 맞춰 자동 조정됩니다. 전압축은 오프셋 표기 없이 실제 전압(V) 값을 표시합니다.

그래프 위 표시줄에는 왼쪽부터 **Y축 소수 자릿수**, 현재 전압, Max, Min, Diff(Max-Min), Avg가 표시되고 통계 항목은 괄호로 구분됩니다. 오른쪽에는 **측정 시작** 이후 경과 시간이 `*Elapsed Time: hour min sec` 형식으로 표시됩니다. **Y축 소수 자릿수** 선택 상자에서 0~6자리를 고르면 그래프 선과 전압축 범위가 그 자릿수로 반올림되어 표시되며, 실시간 전압, 통계, Y축 눈금, 그래프 포인트 툴팁 및 하단 상태 표시도 같은 자릿수로 바뀝니다. 반면 저장 데이터와 CSV/Excel 원본 값은 반올림하지 않으며 통계도 원본 측정값으로 계산합니다.

측정값은 `%LOCALAPPDATA%\Agilent34401A\Recordings`에 측정 중 자동으로 SQLite 파일에 기록됩니다. 그래프에는 최대 2,000개로 요약한 점만 올려 장시간 측정 시에도 메모리 사용량이 누적되지 않게 했습니다. **CSV 저장**과 **Excel 저장**은 전체 기록을 백그라운드에서 내보냅니다. Excel 행 한도를 넘는 기록은 여러 시트로 나뉘어 저장됩니다. CSV/Excel로 내보내기 전에도 자동 기록 파일은 그대로 보존됩니다.

패리티는 없음(8 data bits), 홀수(7 data bits), 짝수(7 data bits)를 지원합니다. 계측기와 프로그램의 패리티 설정을 일치시키세요.

프로그램은 매 측정마다 `MEAS:VOLT:DC?` 질의를 보내 전압을 읽습니다. 측정 응답이 시간 초과되면 `SYST:ERR?`를 보내 오류 큐의 `+0` 응답까지 확인해 질의 상태를 재동기화한 뒤 최대 3회 자동 재시도합니다. 재동기화 명령과 계측기 응답은 원시 로그에 남습니다. 로그의 `RX`는 COM 포트에서 실제 읽은 바이트이고, `HEX`의 `0D 0A`는 응답의 CR/LF 줄 끝입니다. 재시도 이후에도 `RX`에 `(응답 없음)`이 표시되면 선택한 응답 대기 시간 내에 응답 바이트를 받지 못한 것입니다.

Hour, Min, ms 입력 범위에서 가장 작은 양수 간격은 1 ms이며, 최대 설정 조합은 24시간 + 60분 + 30,000 ms(25시간 30초)입니다. 실제 측정 간격은 계측기의 측정 속도, 적분 시간 및 RS-232 통신 속도에 따라 설정값보다 더 길어질 수 있습니다.
