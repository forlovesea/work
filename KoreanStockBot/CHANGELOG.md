# 변경 내역

## v1.0.24 — 2026-10-13 · 사용자 행동 안내와 KRX 검증 상세

- 첫 자료 수집 중에는 '첫 수집 진행 중—분석 완료 대기'로 표시하며 조회 중단 문구를 붙이지 않습니다.
- 창 하단 우측에 고정 상태 안내를 추가했습니다. 진행 파랑, 지연/확인 노랑, 중단/오류 빨강, 완료 초록과 함께 다음 행동을 안내합니다.
- KRX 구성정보 검증 실패에 ETF 종목코드, 구체적인 오류 분류, 관측 비중과 허용 범위를 기록합니다. 화면·수집 로그·공유 ZIP에서 확인할 수 있습니다.
- 전체 수집과 개별 종목 제외를 구분하며 기존 비중 검증 기준과 매매 제한은 유지합니다.

## v1.0.23 — 2026-10-13 · 전체 수집 진행과 중단 상태 구분

- ETF 검사, 기업 재무, 뉴스 검색의 완료/전체 개수와 경과 시간을 표시합니다.
- 재무 조회 뒤 뉴스가 시작되는 순서를 안내하고 개별 구성정보 제외와 전체 수집 실패를 구분합니다.
- 프로그램 중지 시 수집 상태를 '수집 중단'으로 기록하고 중지 후에도 화면에 최종 수집 상태를 표시합니다.
- 이미 끝난 수집 프로세스를 늦게 확인했다고 시간 초과로 오판하지 않도록 수정했습니다.
- 진단 ZIP에도 진행 개수와 수집 중단 상태를 포함합니다.

## v1.0.22 — 2026-10-13 · 공유 가능한 진단 로그

- ETF·단일종목 화면에 진단 로그 파일 생성 체크박스와 공유용 진단 ZIP 저장 버튼을 추가했습니다.
- 설정은 다음 실행에도 유지하며, 로그는 한국시간·버전·단계별 결과·오류 코드·중지 확인을 한글로 기록합니다.
- ZIP에는 이번 실행 요약과 진단 기록, 허용된 필드만 추출한 최근 기본 수집 기록을 포함합니다.
- 인증키·계좌번호/선택값·주문 ID·환경변수·원본 API 응답은 포함하지 않습니다. 금액 설정과 처리 개수는 포함됩니다.
- 기록을 끄면 추가 진단 기록을 중단합니다. 기존 파일 및 기본 수집/주문 감사 기록은 유지됩니다.
- 진단 파일은 파일당 약 2MB, 실행 세션별 백업 3개로 순환하며 로그 실패가 매매 작업을 중단하지 않도록 처리합니다.

## v1.0.21 — 2026-10-13 · 후보조회 한글 깨짐 및 수집 파일 접근 충돌 수정

- 작업 프로세스의 JSON 한글을 Unicode 이스케이프로 전달해 Windows 인코딩과 무관하게 복원합니다.
- 상태·분석 파일 교체 시 일시적인 접근 충돌을 최대 1초 재시도하고, 실패하면 기존 완성 파일을 유지합니다.
- 분석 파일이 없고 수집 기록에 파일 접근 실패가 있으면 후보조회 화면에 원인과 조치 안내를 함께 표시합니다.
- 파일 접근 오류를 별도 분류하고 운영체제 오류 번호를 기록합니다. 인증값·파일 경로는 오류 메시지에 노출하지 않습니다.

## v1.0.20 — 2026-10-13 · 계좌조회 출력 형식 회귀 수정

- v1.0.19의 통신 진행 메시지가 계좌조회 JSON 앞에 섞여 화면에서 계좌 목록을 읽지 못하던 문제를 수정했습니다.
- 계좌조회는 단일 JSON 목록만 출력하며 매매 감시에서는 기존 진행 상태 표시를 유지합니다.
- 인증·계좌 응답을 모의한 실제 조회 코드로 단일/복수/빈 계좌 목록과 GUI 선택 흐름을 검증합니다.

## v1.0.19 — 2026-10-13 · 자료 수집 분류 오류 및 중지 지연 수정

- 실제 KRX 일반·실물(패시브/액티브) 분류값을 인식합니다. 기존 분석 캐시는 새 분류 버전으로 다시 생성합니다.
- 구조 검사 통과/제외 수를 표시하고 전부 제외된 경우 재무·뉴스 생략 이유를 안내합니다.
- 증권사 조회 중 중지 신호를 감지하고, 신규 주문 의도 저장 전에 중지 여부를 재확인합니다.
- 증권사 요청에 전체 20초 제한을 적용하고 진행 상태를 표시합니다. 시간 초과 주문은 재전송하지 않습니다.
- 중지 정리를 1초 간격으로 확인하며, 45초 안에 확인하지 못하면 미확인 종료로 처리합니다.
- 수집 진행 상태가 120초 이상 갱신되지 않으면 수집 프로세스를 종료하고 실패 상태를 기록합니다.
- 저장된 2026-10-12 KRX 자료 재검증: 상위 20개 중 구조 검사 통과 13개, 제외 7개.
