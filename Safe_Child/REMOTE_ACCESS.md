# Safe Child 외부 접속 안내

부모 휴대폰의 브라우저에서 집 PC의 Safe Child에 직접 접속하는 기능입니다. 별도 중계 서버나 휴대폰 앱은 필요하지 않습니다. PC와 Safe Child의 스마트폰 연결 서버가 실행 중이어야 합니다.

## 1. 준비할 항목

- 집 공인 IP를 가리키는 DDNS 또는 도메인 주소. DDNS 갱신은 공유기 또는 PC에서 설정합니다.
- 이 주소에 대한 HTTPS 서버 인증서: **개인 키가 포함된 `.pfx` 또는 `.p12` 파일**과 파일 비밀번호.
- PC 내부 IP에 대한 공유기 DHCP 주소 예약.
- PC 네트워크 프로필을 ‘개인’ 또는 도메인 네트워크로 설정.

인증서의 SAN(대상 이름)이 접속 도메인과 일치해야 합니다. 만료되었거나 개인 키가 없거나 서버 인증용이 아닌 인증서는 시작 시 거부됩니다. 휴대폰이 신뢰하는 인증기관의 인증서를 사용해야 경고 없이 접속할 수 있습니다. 도메인/DDNS 등록과 인증서 발급·갱신은 별도로 진행해야 하며 앱이 자동 발급하지는 않습니다.

인증서 발급 도구에서 PEM만 받은 경우 개인 키와 인증서 체인을 포함해 PFX로 내보낸 뒤 선택합니다. `.cer` 파일만으로는 서버를 시작할 수 없습니다.

## 2. 공유기 포트포워딩

아래 주소와 포트는 예시입니다. 실제 PC 주소로 바꿔 설정하세요.

| 설정 | 예시 |
|---|---|
| 프로토콜 | TCP |
| 외부 포트 | 47831 |
| 내부 IP | 192.168.35.100 |
| 내부 포트 | **47831** |

Safe Child의 PC 수신 포트는 47831입니다. 외부 포트를 443 또는 다른 포트로 지정해도 됩니다. 외부 HTTPS 주소에는 **공유기의 외부 포트**를 사용합니다. 예를 들어 외부 443 → 내부 47831이면 주소는 `https://myhome.example.com`입니다.

공유기의 WAN에 공인 IP가 있어야 합니다. 공유기가 두 겹이면 상위 공유기의 전달 설정도 필요할 수 있습니다. 통신사 CGNAT 환경에서는 통신사에 공인 IP 사용 가능 여부를 확인해야 합니다. SK 장비의 메뉴 이름은 모델마다 다릅니다.

## 3. PC에서 외부 접속 시작

1. Safe Child를 Windows 관리자 권한으로 실행합니다.
2. 앱의 **관리자 모드**로 인증한 뒤 **스마트폰 제어** 탭을 엽니다.
3. **외부 접속 사용 (관리자 전용)**을 켭니다.
4. **외부 HTTPS 주소**에 `https://myhome.example.com:47831`처럼 입력합니다. 경로·쿼리는 넣지 않습니다.
5. **인증서 선택**으로 PFX 파일을 지정하고 인증서 비밀번호를 입력합니다. 비밀번호가 없는 PFX는 빈칸으로 둡니다.
6. 공유기에서 전달할 **PC의 내부 네트워크 주소**를 선택합니다.
7. **QR 연결 시작**을 누릅니다.

시작에 성공하면 외부 접속 주소·QR, 공유기에 입력할 포트 전달 정보, 인증서 만료일이 표시됩니다. Windows 방화벽에는 선택한 PC 주소의 TCP 47831, 현재 Safe Child 실행 파일, 개인·도메인 프로필에 한정한 규칙이 생성됩니다. 공유기 설정은 앱이 변경하지 않습니다.

입력한 주소·인증서 경로·접속 링크는 시작 성공 과정에서 저장됩니다. **인증서 비밀번호는 저장하지 않습니다.** 앱 재실행 후에는 관리자 모드에서 필요한 인증서 비밀번호를 입력하고 연결을 다시 시작해야 합니다. 연결을 시작한 뒤 앱의 관리자 모드를 잠가도 서버는 계속 실행됩니다.

## 4. 휴대폰에서 접속

1. **접속 주소 복사** 또는 QR로 주소 전체를 휴대폰에 저장합니다.
2. 휴대폰 Wi-Fi를 끄고 LTE·5G에서 해당 주소를 엽니다.
3. **이 PC에 설정한 관리자 비밀번호**로 로그인합니다. 인증서 파일 비밀번호와는 다른 비밀번호입니다.
4. 사이트별 차단·요일별 시간표 또는 전체 일시 허용을 설정합니다.

접속 주소 끝의 긴 문자열도 포함해야 합니다. 도메인 주소만 입력하면 접속되지 않습니다. 인증은 15분간 유지되며, 앱에서 관리자 비밀번호를 바꾸면 기존 모바일 인증도 해제됩니다.

외부 링크는 앱을 재실행해도 유지됩니다. **연결 중지 → 외부 접속 링크 새로 발급 → QR 연결 시작**으로 바꾸면 이전 링크는 사용할 수 없습니다. 새 링크를 휴대폰에 다시 저장하세요.

일부 공유기는 같은 집 Wi-Fi에서 공인 주소로 돌아오는 접속을 지원하지 않습니다. 외부 모드 검증은 LTE·5G에서 하세요. 외부 모드에서는 등록한 외부 주소로 접속해야 합니다.

## 5. 중지·인증서 갱신

- 외부 연결 중지는 앱의 관리자 모드에서 할 수 있습니다. 서버와 해당 Windows 방화벽 규칙을 제거합니다.
- 내부 전용으로 돌아가려면 연결 중지 후 **외부 접속 사용**을 끄고 다시 시작합니다.
- 인증서를 갱신하면 연결 중지 후 갱신된 PFX를 선택하고 다시 시작합니다. 도메인과 접속 링크가 같으면 휴대폰의 즐겨찾기는 유지됩니다.
- PC가 잠들거나 인터넷이 끊기거나 앱이 종료되면 접속할 수 없습니다. 앱 자동 실행과 스마트폰 연결 서버 시작은 별개입니다.

## 문제 확인

| 증상 | 확인할 항목 |
|---|---|
| 연결 시작 실패 | PFX 경로·비밀번호, SAN 대상 이름, 유효 기간, Windows 관리자 권한, 47831 포트 충돌 |
| LTE·5G에서 연결 시간 초과 | DDNS IP, 공유기 공인 IP, 포트포워딩 대상 PC, Windows 개인 네트워크 프로필, PC 절전 상태 |
| 인증서 경고 | 접속 도메인, 인증기관 신뢰, 인증서 체인 및 만료 여부 |
| 403 응답 | 외부 주소와 포트가 앱에 등록한 값인지 확인. 내부 IP로 접속하거나 다른 도메인을 사용하면 거부됨 |
| 404 응답 | 주소 끝의 접속 문자열이 누락되었거나 예전 링크를 사용 중인지 확인 |
| 로그인 실패 | PC 관리자 비밀번호인지 확인. 인증서 비밀번호·마스터 비밀번호는 외부 로그인에 사용하지 않음 |
| 인증 요청이 많다는 표시 | 1분 후 재시도 |

프로그램 검증은 로컬 HTTPS 서버에서 외부 주소와 포트 전달을 모의해 수행했습니다. 실제 집 공유기·DDNS·휴대폰 회선을 통한 최종 연결은 위 순서로 확인해야 합니다.
