# 토스증권 실전 자동주문

**현재 start_live.bat와 start_etf.bat는 GUI를 엽니다.** 인증·계좌 설정, 실전 시작·중지와 기간별 그래프는 [GUI_GUIDE.md](GUI_GUIDE.md)를 따릅니다. 아래 키보드 입력은 `python launch_live.py`로 실행하는 기존 콘솔 기준입니다.

이 문서는 기존 단일 일반주식 모드 기준입니다. **코스닥 ETF 순자산 상위 20개 모드**는
`start_etf.bat`로 실행하며 [ETF_GUIDE.md](ETF_GUIDE.md)의 자료 준비·분석·익절 기준이 적용됩니다.

공식 OpenAPI **1.2.24** 명세(2026-10-11 조회)를 기준으로 구현했습니다.
코드와 모의 API 테스트를 검증했으며 실제 계좌 접속/주문 검증은 아직 하지 않았습니다.
실전 실행에는 본인의 API 서비스 신청, 허용 IP, 키, 계좌 선택, 종목 설정이 필요합니다.

## 처음 실행

1. [공식 시작 안내](https://openapi.tossinvest.com/openapi-docs/overview.md)에 따라 토스증권 웹 **설정 → Open API**에서 키를 발급받고 공인 IP를 등록합니다.
2. `start_live.bat`를 더블클릭합니다. 이 파일이 실전용이고, 기존 `start.bat`는 오프라인 모의매매 화면입니다.
3. 거래할 국내 보통주 6자리 코드를 입력합니다. 종목을 추천하거나 자동 선정하지 않습니다. ETF/ETN/우선주/해외주식은 이 버전에서 제외합니다.
4. `Client ID`, `Client Secret`을 로컬 콘솔에 입력합니다. 입력 내용은 화면에 표시하지 않으며 파일에 저장하지 않습니다. 키를 채팅에 보내지 마세요.
5. 표시된 `accountSeq` 중 사용할 종합매매 계좌를 고릅니다. 계좌번호와 다릅니다.
6. 처음에는 모드에서 **Enter**를 눌러 읽기 전용으로 점검합니다. 장외에는 `OUTSIDE_REGULAR_SESSION`이 표시됩니다.
7. 설정과 신호를 확인한 뒤 다시 실행하여 모드에 **LIVE**를 입력하면 실제 지정가 주문 루프가 시작됩니다.

이 프로그램이 관리하는 매매만 있는 계좌에서 사용하세요. 최초 실행 시 기존 보유 주식/미체결/조건주문이 있으면 시작을 거부합니다.
실행 중 다른 기기, 수동 매매, 다른 봇에서 같은 계좌를 사용하면 잔고 불일치 또는 미관리 주문으로 중단합니다.
한 PC의 이 폴더에서는 파일 잠금으로 중복 실행을 막지만, 다른 폴더/PC의 봇까지 잠글 수는 없습니다.

## 기본 설정

`live_config.json`에서 **최초 실전 실행 전에** 설정합니다.

| 항목 | 기본값 | 동작 |
|---|---:|---|
| 운용 원금 | 30,000원 | 다른 현금이 있어도 봇의 원금으로 자동 편입하지 않음 |
| 투자 비중 | 평가자산의 30% | 매수 가능 현금/한도 중 작은 값 적용 |
| 1회 매수 상한 | 9,000원 | 매수 비용 여유분 포함, 1주도 못 사면 대기 |
| 단기/장기 평균 | 5일 / 20일 | 전 영업일까지 완성된 수정 일봉 사용 |
| 개별 손절 / 익절 | 3% / 10% | 현재가 기준 신호, 최우선 매수호가에 지정가 매도 |
| 일 손실 중단 | 2% | 해당 일 신규 매수 중단 및 보유분 청산 시도 |
| 최대 낙폭 중단 | 10% | 영구 중단 상태 저장, 보유분 청산 시도 |
| 일 / ISO 주 / 월 목표 | 각각 10% | 어느 기간이든 달성하면 청산 시도 후 그 기간 신규 매수 중단 |
| 신규 매수 횟수 | 하루 최대 1회 | 거부/취소된 진입도 당일 자동 반복하지 않음 |
| 미체결 취소 | 제출 120초 후 | 남은 수량 취소 요청, 확정 전 신규 주문 금지 |
| 시세 최대 나이 | 15초 | 오래된 시세이면 중단 |
| 최대 호가 스프레드 | 0.5% | 초과하면 매수/매도 모두 대기 |
| 점검 간격 | 30초 + API 소요시간 | 폴링, 프로세스 실행 중에만 작동 |

정규장 캘린더의 시작 2분 후부터 마감 단일가 시작 2분 전까지 주문합니다.
공휴일/특별 개장 시간은 공식 캘린더를 사용합니다. 시간외 매매는 하지 않습니다.
일봉 추세가 상승이면 진입하고 하락 전환이면 청산합니다. 오늘의 미완성 봉은 제외합니다.
국내 현금 정수 주식만 거래합니다. 시장가 주문, 신용, 물타기, 목표 미달을 이유로 한 투자 확대는 없습니다.

손절/목표는 체결 보장이 아닙니다. 지정가 미체결, 넓은 호가 간격, 거래정지, API 장애,
프로그램 종료 또는 장외 시간에는 청산되지 않을 수 있으며 설정 손실률을 초과할 수 있습니다.
부분체결 주문이 진행 중이면 해당 주문 확인/취소를 먼저 처리하고, 청산 판단은 그 뒤 진행합니다.

## 복리와 성과 기록

수익/손실과 API가 보고한 실제 체결 수수료·세금을 현금 장부에 반영하므로 다음 매수 금액에도 반영됩니다.
다만 기본 1회 9,000원 상한은 유지됩니다. 목표를 위해 한도를 자동으로 늘리지 않습니다.

일/주/월 수익률은 봇의 **관측한 평가자산** 기준입니다. 기간이 바뀌면 직전 관측값을 기준으로 삼습니다.
첫 실행일 및 장기간 꺼 두었던 구간은 정확한 일별 종가 수익률이 아닙니다.
평가액은 현금 + 보유 수량 × 매수호가에 현재 수수료와 **청산비용 여유분 0.4%**를 차감한 추정치입니다.
0.4%는 법정 세율이 아닙니다. 실제 체결 후에는 주문 API의 세금/수수료를 사용합니다.
입금/출금은 봇 수익으로 잡지 않으며, 출금으로 실제 매수 가능금액이 줄면 그 금액을 우선 적용합니다.

목표 달성 상태는 기간 중 다시 하락해도 유지됩니다. 일/주/월 중 **하나라도** 목표에 도달하면
그 기간이 끝날 때까지 신규 진입을 쉬므로 월 목표 달성 시 다음 달까지 기다릴 수 있습니다.
각 기간 10%는 사용자 목표이며 전략의 예상 수익률이나 수익 보장이 아닙니다.

## 중지와 재시작

- `stop_live.bat`를 실행하면 `STOP` 파일을 만듭니다. 봇은 다음 점검에서 자기 미체결을 취소 요청하고 완료를 확인한 뒤 종료합니다. **보유 주식은 그대로 유지**합니다.
- 프로그램이 꺼져 있거나 통신에 실패하면 이 파일만으로 증권사 주문을 취소할 수 없습니다. 토스 앱에서 직접 확인하세요.
- `Ctrl+C`/창 닫기는 프로세스만 중지합니다. 기존 주문과 주식은 증권사에 남습니다.
- 재시작할 때는 주문 상태를 확인한 뒤 `STOP` 파일만 삭제하고 같은 설정/계좌로 실행합니다.
- `runtime/live_state.json`은 실제 주문 장부입니다. **삭제/초기화/직접 수정을 하지 마세요.** 부분체결을 포함해 재시작 시 중복 반영을 방지합니다.
- 설정/계좌를 변경하면 기존 상태와 달라 실행을 거부합니다. 운용 중 변경은 주문·잔고 정산 후 별도의 상태 마이그레이션이 필요하며 자동 초기화 기능은 없습니다.
- 최대 낙폭 중단은 재시작해도 해제되지 않습니다. 원인 확인 없이 상태 파일을 지워 재개하지 마세요.

## 통신 오류와 주문 복구

주문 전송 전에 주문 의도와 고유 `clientOrderId`를 디스크에 저장합니다.
토스의 멱등성 키는 **10분만 유효**하므로, 응답 유실 시 자동 재전송하지 않습니다.
`UNKNOWN order outcome`이면 토스에서 주문 접수 여부를 확인하세요.

실제로 접수된 주문의 API `orderId`를 확인했다면 같은 환경변수/설정으로:

```powershell
python live.py --live --recover-order "확인한_orderId"
```

이 명령은 종목·방향·수량·가격·접수 시각을 대조해 기존 주문과 장부를 연결합니다. 재주문하지 않습니다.
실제로 접수되지 않은 것이 확인되거나 ID를 찾지 못한 경우에도 장부를 지워 재시도하지 말고,
주문 내역과 계좌 정산을 바탕으로 복구해야 합니다. 자동으로 '주문 없음'을 추정해 재개하지 않습니다.
취소 결과도 불명확하면 자동 반복 취소를 하지 않으며 토스에서 잔량을 확인해야 합니다.

## CLI

콘솔 안내 실행은 `python launch_live.py`입니다. 반복 실행을 직접 구성할 때는 로컬에서
`TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`, `TOSS_ACCOUNT_SEQ` 환경변수를 설정합니다.

```powershell
python live.py --accounts            # 계좌 선택자만 조회; 계좌번호 출력 없음
python live.py --once                # 읽기 전용 1회 점검
python live.py                       # 읽기 전용 연속 점검
python live.py --live                # 실제 자동주문
python -m unittest -v                # 네트워크/실계좌 없이 검증
```

읽기 전용 실행은 `runtime/dry_state.json`만 저장합니다. 실전 상태가 있으면 복사본으로 점검합니다.
실전 상태, 계좌 선택자, 주문 ID가 들어갈 수 있는 `runtime/`은 Git에서 제외했습니다.
ETF 실행에서는 선택에 따라 API 인증값을 Windows DPAPI로 암호화해 `runtime/credentials.dpapi`에 저장합니다.
같은 Windows 사용자 환경에서 재사용하며, 평문 키는 저장하지 않습니다. 토큰은 메모리에서만 유지합니다.

## 검증 범위

모의 API로 실전 주문 형식, 예산, 부분체결/재시작, 응답 유실, 복구 대조, 미체결 취소,
중지, 오래된 시세, 휴장일, 종목 경고, 외부 주문/조건주문/보유 감지,
목표 달성 유지/기간 변경, 손절 매도, 현금 장부, Windows 파일 잠금을 검사합니다.
이는 실제 체결 검증 또는 수익성 검증을 대신하지 않습니다.

공식 자료: [OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json),
[시작 및 인증](https://openapi.tossinvest.com/openapi-docs/overview.md).
