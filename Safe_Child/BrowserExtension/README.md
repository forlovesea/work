# 전달 메시지 연결

1. SafeChild를 실행하고 관리자 모드 → 전달 메시지 → **확장 폴더 열기**를 누릅니다.
2. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 이 폴더를 선택합니다.
4. SafeChild에 **브라우저 연결됨**이 표시되는지 확인합니다.
5. URL/도메인 차단에서 도메인을 등록하고, 전달 메시지에서 해당 도메인의 메시지를 저장합니다.
6. 일반 모드로 전환하고 차단한 주소를 새로 열거나 새로고침하면 PC에 메시지가 표시됩니다.

자녀가 사용하는 각 Chrome/Edge 프로필에 설치해야 합니다. 시크릿/InPrivate에서도 사용할 경우 확장 설정에서 해당 모드를 허용하세요. 확장 폴더를 이동하거나 삭제하면 다시 로드해야 합니다.

PC 앱과 확장이 모두 켜져 있어야 팝업이 동작합니다. 앱을 나중에 켜면 자동으로 다시 연결하며, 연결된 뒤 접속을 다시 시도하세요. 확장은 현재 차단 중이고 메시지가 있는 도메인만 앱에 알립니다. 메시지가 없거나 시간 만료·차단 해제·모든 사이트 허용 중이면 알리지 않습니다. 도메인과 해당 www 주소에 적용되며 임의의 하위 도메인은 별도로 등록해야 합니다.

팝업은 한 개만 유지하고 새 메시지로 내용을 바꿉니다. 같은 도메인은 마지막 표시 후 30초 동안 반복 알림을 제한합니다. 열린 페이지 자체를 닫거나 이미 내려받은 내용을 지우지는 않습니다.

이 확장은 외부 서버를 사용하지 않습니다. PC 내부 127.0.0.1:47832에 사이트의 origin만 전달하며 경로·검색어·페이지 내용·관리자 비밀번호는 보내지 않습니다. 확장을 끄면 메시지는 표시되지 않지만 기존 차단 기능은 유지됩니다.
