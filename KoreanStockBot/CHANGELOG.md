# 변경 내역

## v1.0.18 — 2026-10-12 · 후보 제안 불가 사유 팝업

- 후보 없음과 조회 실패 시 구체적 원인 팝업 및 하단 로그를 표시합니다.
- 실제 캘린더 시장 상태, 오래된 시세, 예산·추세·재무 조건 미달을 구분합니다.
- 분석 자료 만료, 인증/접근 오류, 통신·조회 시간 초과를 별도로 안내합니다.

## v1.0.17 — 2026-10-12 · 프로그램 종료 버튼

- 우측 상단 고정 종료 버튼과 창 X에 동일한 종료 절차를 연결합니다.
- 조회 완료 및 미체결 정리·정상 종료 응답을 기다린 뒤 자동으로 닫습니다.
- 정상 중지 미확인·중지 요청 실패 시 창을 유지합니다. 종료 준비 중 신규 시작을 차단합니다.
- 모의매매 종료 시 현재 결과를 자동 저장하며 실패 시 종료를 보류합니다.

## v1.0.16 — 2026-10-12 · 자산·시장 기반 ETF 후보 선택

- 겹치는 순위 범위 선택 UI를 실제 종목 추천·선택 표로 교체합니다.
- 읽기 전용 계좌·시세 조회로 예산, 재무·뉴스, 추세를 검사하고 제외 사유를 표시합니다.
- 사용자가 선택한 종목만 신규 매수 대상으로 제한하며 기존 보유분 매도는 유지합니다.
- 중복 종목 제거, 5분 경과 시 재조회, 자료 미확인 시 추천 보류를 적용합니다.

## v1.0.15 — 2026-10-12 · 주식 차트 아이콘

- 실행파일과 창·작업표시줄·팝업의 기본 아이콘을 주식 캔들 및 상승 그래프로 변경합니다.
- 16~256px Windows 아이콘을 포함하고 ETF·단일종목·모의매매에 공통 적용합니다.

## v1.0.14 — 2026-10-12 · 중지 처리 상태 개선

- 중지 요청 접수, 주문 조회·정리 확인, 정상 중지 완료, 비정상 종료를 구분합니다.
- 중지 요청 후 경과 시간과 60초 이상 처리 지연을 표시합니다.
- 점검 사이 대기 중 중지 요청을 빠르게 감지합니다. 진행 중인 통신은 응답 후 처리합니다.
- 정상 종료 코드와 STOPPED 수신을 모두 확인해야 중지 완료로 표시합니다.

## v1.0.13 — 2026-10-12 · 수집 단계·오류 로그

- research/logs/collection.log에 수집 실행 ID, 한국시간, 단계 시작·완료·실패 기록.
- ETF 목록·기본정보·구성종목, DART 기업코드·재무, NAVER 뉴스 단계 구분.
- 안전한 오류 분류와 HTTP 상태 코드 기록. 키·URL·헤더·원문 오류 메시지는 제외.
- 미요청·진행 중·상위 단계 실패를 화면에서 구분. 2MB 로그 파일과 백업 5개로 용량 제한.

## v1.0.12 — 2026-10-12 · ETF 후보 범위 제안

- ETF GUI에 후보 범위 제안 버튼 추가. 1~20위, 1~10위, 10~20위, 11~20위 비교 및 사용자 선택.
- 재무·뉴스와 예산 통과 후보 수를 비교하며, 추세·호가·위험 조건은 매수 전 다시 검사.
- 중지 후 범위를 저장하고 재시작하면 신규 매수에 적용. 보유분·기존 매도 조건·거래 기록 보존.

## v1.0.11 — 2026-10-12 · ETF 진단 강화

- 신규 매수 대기 사유를 ETF별 수치·재무점수·확인 비중·뉴스 수·예산·추세로 표시.
- 후보 선별에도 실제 계좌 원화 현금매수가능 금액을 상한으로 반영.
- KRX·DART·NAVER API 성공 / 캐시 사용 / 오류 횟수와 기록 시각 표시.
- READY와 API 인증 성공, 매수 조건 통과를 구분하여 안내.
