**이전 버전 참고 자료입니다.** Master 인증·이메일 승인·회의록 저장 등 최신 절차는 [역할별 사용 매뉴얼](../문서/사용매뉴얼.md)을 우선하세요.

# 방장 사용법

방을 만든 사람이 처음 방장이 됩니다. 방장은 회의 방식과 자동 기록 여부를 정하고 발표 순서를 관리합니다. 본인의 장치 조작은 [일반 참여자 사용법](01_일반_참여자_사용법.md)과 같습니다.

## 1 방을 만들기 전에 정하기

| 선택 | FREE Talk | 회의 모드 |
| --- | --- | --- |
| 말하는 방식 | 여러 사람이 동시에 발언 | 지정된 발표자 한 사람만 발언 |
| 자동 회의록 | 사용할 수 없음 | 서버에 한국어 모델이 있으면 선택 가능 |
| 적합한 상황 | 자유 대화, 비공식 의견 교환 | 순서 있는 발표, 회의록이 필요한 회의 |
| 화면 공유·화이트보드 | 지정된 발표자만 조작 | 지정된 발표자만 조작 |

방의 방식은 생성할 때 선택합니다. **진행 중인 방을 FREE Talk에서 회의 모드로 바꾸는 버튼은 없습니다.** 변경하려면 기록을 저장하고 새 방을 만든 뒤 새 접속 ID를 공유하세요.

## 2 새 방 만들기

1. 서버 관리자가 알려준 HTTPS 주소를 Chrome 또는 Edge에서 엽니다.
2. **중계 서버 주소**를 확인하고 **연결 확인**을 누릅니다.
3. **내 이름**을 입력합니다. 예: `김민수 팀장`.
4. 마이크·스피커·카메라 사용 여부를 정합니다. 기본값은 모두 꺼짐입니다.
5. **새 회의 만들기** 탭을 선택합니다.
6. **회의 이름**을 입력합니다. 예: `제품팀 주간 회의`. 최대 80자입니다.
7. **회의 방식**에서 FREE Talk 또는 회의 모드를 선택합니다.
8. 자동 기록이 필요하면 회의 모드에서 **음성 인식으로 자동 회의록 작성**을 선택합니다.
9. **새 회의 시작하기**를 누릅니다.
10. 회의 화면에서 본인의 **방장** 표시, 회의 이름, 접속 ID를 확인합니다.

방을 만들면 방장 자신이 최초 발표자로 지정됩니다. 마이크가 꺼져 있다면 발표자여도 음성이 나오지 않으므로 직접 켜야 합니다.

자동 회의록 옵션이 비활성화되어 있으면 FREE Talk가 선택됐는지, 서버 연결 확인이 성공했는지, 안내에 한국어 모델 미설치 또는 로딩 실패가 표시되는지 확인하세요. 모델 설치 문제는 서버 관리자가 해결해야 합니다.

## 3 초대 링크·접속 ID 공유와 참석자 확인

1. 방을 만든 뒤 오른쪽 **참석자** 탭에서 **참여자 초대 링크**를 확인합니다. 방장에게 표시되는 메뉴입니다.
2. **초대 링크 복사**를 누르고 이메일·메신저 등 원하는 수단에 붙여 넣습니다.
3. 참석자에게 링크를 열고 이름과 장치 설정을 확인한 뒤 **회의 참여하기**를 누르도록 안내합니다. 서버 주소와 방 접속 ID는 자동 입력됩니다.
4. 오른쪽 **참석자** 탭에서 이름과 인원수를 확인합니다.

공유 예:

```text
회의: 제품팀 주간 회의
초대 링크: https://meet.example.com/#room=4AB891762964

링크를 열고 이름을 입력한 뒤 회의 참여하기를 눌러 주세요.
마이크와 스피커는 기본 꺼짐입니다.
입장 후 스피커를 켜고, 발언할 때는 손들기를 눌러 주세요.
```

방 접속 ID는 서버가 자동으로 생성합니다. 방장이 직접 지정하거나 기존 방의 ID를 바꾸는 기능은 없습니다. 코드 자체가 입장 수단이므로 참석할 사람에게 공유하세요. 현재는 방장 승인 대기실이나 별도 입장 비밀번호가 없습니다.

클립보드 복사가 실패하면 링크 입력란이 선택됩니다. `Ctrl+C` 또는 모바일의 길게 누르기로 직접 복사하세요. 기존 상단 **접속 ID 복사**로 서버 주소와 접속 ID를 전달하는 방법도 사용할 수 있습니다.

초대 링크에는 방 접속 ID만 포함되고 방장 인증 토큰은 포함되지 않습니다. 링크를 받은 사람은 일반 참여자로 입장합니다. 다른 사람에게 전달된 링크로도 입장할 수 있으므로 참석할 사람에게 공유하세요. 방장이 먼저 나가면 다음 방장에게 초대 메뉴가 표시됩니다.

마지막 참석자가 나가거나 서버가 재시작되어 방이 종료되면 기존 링크로 재입장할 수 없습니다. 새 방을 만들고 새 링크를 공유하세요. localhost 주소는 다른 PC용 초대 주소로 사용할 수 없습니다. 외부 초대는 참석자가 접속할 수 있는 HTTPS 서버 주소로 접속해 방을 만든 뒤 링크를 복사합니다.

## 4 회의 시작 점검

1. 전원에게 스피커를 켜 달라고 안내합니다.
2. 본인이 발표자인지 확인하고 마이크를 켭니다.
3. 짧게 말한 뒤 참석자가 듣는지 확인합니다.
4. 참석자 한 명을 발표자로 지정해 반대 방향 음성도 확인합니다.
5. 화면 공유와 화이트보드를 쓸 예정이면 각 기능을 한 번 확인합니다.
6. 자동 회의록을 사용하는 회의임을 참석자에게 알리고 기록 상태를 확인합니다.

서버 주소가 열리고 방에 입장할 수 있다는 것만으로 영상·음성이 연결된 것은 아닙니다. 다른 네트워크의 참석자가 있다면 그 참석자의 영상·음성도 확인하세요.

## 5 발표 순서 운영하기

### 5.1 일반 참여자에게 발표권 주기

1. 오른쪽 **참석자** 탭을 엽니다.
2. 발언을 요청한 사람의 이름 옆에 **발언 요청** 표시가 있는지 확인합니다.
3. 해당 사람의 **발표 지정** 버튼을 누릅니다.
4. 해당 사람이 **발표자**로 표시되는지 확인합니다.
5. 그 사람의 마이크가 꺼져 있다면 직접 켜 달라고 안내합니다.

발표자로 지정된 사람의 손들기 표시는 해제됩니다. 이전 발표자의 음성은 회의 모드에서 차단됩니다. 이전 발표자가 화면을 공유 중이었다면 공유도 중지되므로 발표권을 넘기기 전에 설명이 끝났는지 확인하세요.

### 5.2 방장 자신이 다시 발표하기

1. 참석자 목록에서 본인 이름을 찾습니다.
2. 본인 옆 **발표 지정**을 누릅니다.
3. 본인의 마이크를 켜거나 켜진 상태인지 확인합니다.

방장이란 이유만으로 다른 발표자와 동시에 말할 수 있는 것은 아닙니다. 회의 모드에서는 방장에게도 동일한 단일 발표 규칙이 적용됩니다.

### 5.3 FREE Talk 진행하기

FREE Talk에서는 모두 마이크를 켜면 동시에 말할 수 있습니다. 이때 발표자 지정은 주로 공유 화면과 화이트보드 조작자를 정하기 위해 사용합니다. 방장이 다른 사람의 마이크를 강제로 켜거나 끄는 기능은 없습니다.

## 6 자동 회의록 운영하기

### 6.1 진행 중 켜기와 끄기

1. 오른쪽 **회의록** 탭을 선택합니다.
2. 회의 모드에서 **켜기**를 누릅니다.
3. **음성 인식 기록 중** 표시를 확인합니다.
4. 현재 발표자가 마이크를 켜고 말합니다.
5. 발언자 이름과 전사 내용이 표시되는지 확인합니다.
6. 기록을 중지할 때 **끄기**를 누릅니다.

옵션을 켠 뒤의 음성만 인식합니다. 꺼져 있던 구간을 나중에 복구해 기록하지 않습니다. 옵션을 끄거나 발표권이 바뀌는 순간 직전 발언의 마지막 인식 결과가 잠시 뒤 도착할 수 있습니다. 자동 기록을 끄더라도 이미 저장된 기록은 지워지지 않습니다.

### 6.2 정확도를 높이는 진행 방법

- 한 번에 한 사람이 말하고, 말이 끝날 때 짧게 쉬어 줍니다.
- 마이크를 입 가까이에 두고 불필요한 주변 소음을 줄입니다.
- 사람 이름, 제품명, 숫자, 날짜, 약어는 전사 결과를 확인합니다.
- 중요한 결정은 방장이 다시 확인하고 별도의 확정 기록으로 남깁니다.

화면의 자동 전사는 검토할 원문입니다. 현재 버전은 전사를 문맥에 따라 완전히 교정하거나 고급 요약하는 기능이 아닙니다.

### 6.3 확정 결정과 실행 항목 남기기

1. **회의록** 탭의 **방장 기록 추가**로 이동합니다.
2. 종류를 선택합니다.
3. 내용을 작성하고 **기록 추가**를 누릅니다. 한 번에 최대 2,000자입니다.

| 종류 | 기록 예 |
| --- | --- |
| 추가 메모 | `전사 정정: 제품 이름은 모아입니다.` |
| 확정 결정 | `시제품 검토 회의는 10월 21일 수요일 14시에 진행한다.` |
| 실행 항목 | `담당: 홍길동 / 작업: 시제품 화면 초안 공유 / 기한: 10월 20일 18시` |

기존 기록의 편집·삭제 버튼은 없습니다. 잘못 입력했으면 **추가 메모**로 정정 내용을 남기세요. 자동 추출된 결정·실행 후보를 확인했더라도 확정 내용으로 남기려면 방장이 해당 종류로 새로 기록해야 합니다.

### 6.4 회의록 저장 파일의 구성

**회의록 저장**을 누르면 다음 순서로 정리된 Markdown 파일을 내려받습니다.

1. 회의 제목, 시작·내보내기 시각
2. 기록에 등장한 발언자
3. 발언자별 주요 논의 원문
4. 방장이 입력한 확정 결정
5. 방장이 입력한 실행 항목
6. 추가 메모
7. 키워드로 자동 분류한 결정·실행 후보
8. 시간순 원문

`참석 발언자`는 전체 출석부가 아닙니다. 기록에 등장한 사람을 기준으로 하므로 조용히 듣기만 한 사람은 빠질 수 있습니다. 부정문도 키워드 후보로 잡힐 수 있어 자동 후보는 미확정 상태로 분리됩니다.

## 7 발표 자료와 화이트보드 진행

방장도 현재 발표자여야 **화면·파일 공유**와 화이트보드 그리기를 사용할 수 있습니다. 파일을 먼저 연 뒤 공유할 창을 선택하고 참석자에게 **발표자** 화면으로 바꿔 달라고 안내하세요.

화이트보드를 쓸 때는 참석자에게 각자 **화이트보드** 탭을 선택하도록 안내합니다. **지우기**는 전체 내용을 삭제하며 되돌리기 기능은 없습니다. 기록이 필요한 그림은 회의가 끝나기 전에 화면 캡처로 보관하세요.

## 8 회의 종료와 방장 퇴장

### 정상 종료 순서

1. 마지막 발표자의 발언을 마칩니다.
2. 마지막 전사 내용이 표시되는지 확인합니다.
3. 확정 결정과 실행 항목의 담당자·기한을 확인합니다.
4. **회의록 저장**으로 최종 파일을 내려받습니다.
5. 필요한 참석자도 회의록을 저장하도록 안내합니다.
6. 참석자들에게 나가 달라고 안내합니다.
7. 방장은 마지막으로 **나가기**를 누릅니다.

**방장이 나가기만 해서는 전체 회의가 끝나지 않습니다.** 다른 참석자가 남아 있으면 그중 한 사람에게 방장 권한이 자동으로 이전됩니다. 현재는 전체 방 종료 버튼이 없습니다.

### 방장이 먼저 나가거나 연결이 끊긴 경우

- 서버는 남아 있는 접속자 중 먼저 들어온 사람을 우선하여 방장으로 정합니다.
- 원하는 사람을 직접 방장으로 지정하는 UI는 없습니다. 발표자 지정은 방장 이전 기능이 아닙니다.
- 기존 방장이 다시 입장해도 이전 권한이 자동 복구되지 않습니다.
- 모든 사람이 나가면 방은 종료되고 기존 접속 ID로 다시 들어갈 수 없습니다.
- 새로고침도 연결 종료로 처리될 수 있으므로 진행 중인 방장 화면을 불필요하게 새로고침하지 마세요.

## 9 방장 점검표

| 시점 | 확인 사항 |
| --- | --- |
| 회의 전 | 올바른 방식, 모델 준비 상태, 초대 주소, 실제 영상·음성 왕복 |
| 회의 중 | 발표권, 참여자의 마이크 상태, 자동 기록 표시, 전사 오류 정정 |
| 안건 종료 | 확정 결정, 담당자, 기한을 수동 기록 |
| 회의 종료 전 | 마지막 발언 반영, 회의록 다운로드, 필요한 보드 캡처 |
| 퇴장 | 모든 참석자가 나갔는지 확인 후 마지막으로 나가기 |
