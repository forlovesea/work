# V7.0 배터리 모듈 Group 요약

- 실행파일: `Release/TBC1000B_LCD_Modbus_V7.exe`
- 소스: `LCD_GUI_Pannel_Master_modbus_V7.py` (V6 보존)
- RMS 시스템 요약 정보를 참고하여 모듈 목록 위에 독립 영역 추가.
- 모듈 전압 평균/최대/최소, 부호 포함 전류 합계, SOC/SOH 단순 평균, 셀 온도 최대/최소/평균 표시.
- 보호 알람: `0x8431 + (n-1)*64`의 offset 10/8/12(과충전/고온/과전류). 1=발생, 모든 감시 대상이 0=정상, 미수신/실패/미정의 값=확인 불가. 일부 미확인 상태에서도 확인된 발생 알람은 표시.
- 측정값은 기존 `0xA731 + (n-1)*64`, 54개 레지스터 결과 사용. 추가 통신 요청 없음.
- 최근 10초 이내 통신 성공 모듈만 집계. 보호 알람은 배터리 통신 정상 및 알람 수신 15초 이내 조건 적용.
- Auto는 검출된 모듈, 수동은 선택한 수의 모듈을 대상으로 사용. 부분 집계 여부와 유효 모듈/셀 온도 수 표시.
- 유효 범위: SOC/SOH 0~100%, 모듈 전압 0<V<1000, 전류 -10000<A<10000. 셀 온도 -80~150℃, 셀 전압 0<V≤5. 이 범위는 데이터 필터이며 장비 보호 설정값이 아님.
- 연결 해제 시 그룹값 미표시, 재연결 시 캐시 초기화.

전압은 모듈 평균이며 Rack 직접 측정값이 아닙니다. SOC/SOH는 용량 가중값이 아닌 단순 평균입니다. 모듈들은 순차 수신되므로 동일 순간 측정값은 아닙니다. 보호 알람은 충전 전용 차단 여부를 구분하지 않습니다.

현재 코드에서 주소/해석이 확인되지 않는 Rack 용량, 방전 횟수, 차단기 OFF, 충전전류제한, SOC 충전제한은 제외합니다. 기존 레지스터 단위/부호 변환을 유지합니다.
