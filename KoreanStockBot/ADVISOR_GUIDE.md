# 추천종목자동매매 프로그램

`KoreanStockBotAdvisor_v버전.exe`를 실행합니다. `_internal` 및 설정 파일이 필요하므로 배포 폴더 전체를 유지하세요.

## 시작 순서

1. **인증·계좌 설정**에서 토스 Client ID/Secret으로 계좌를 조회하고 선택합니다. KRX 로그인, OpenDART 키, NAVER API HUB 뉴스 키를 입력하고 **암호화 저장**합니다. 이 프로그램의 인증은 `advisor/credentials.dpapi`에 저장합니다. 처음에는 같은 폴더의 기존 암호화 인증을 읽을 수 있지만 덮어쓰지 않습니다.
2. **예산·비용**에서 사용자가 운용할 금액을 정합니다. 계좌 전체 현금을 자동 투입하지 않습니다. 기본 예산 30,000원, 투자 비중 30%, 주문 상한 9,000원입니다.
3. **뉴스·재무 분석**을 실행합니다. KRX의 업종별 시가총액 상위 20개 중 예산 내 종목을 검사하고, 재무 통과 후보에서 상위 12개를 뉴스 검토합니다. 첫 조회는 수 분 걸릴 수 있습니다. 추천 목록을 누르면 공시 기준일·근거·기사 URL을 볼 수 있습니다.
4. **모의 자동매매 시작**을 누르면 기본 30초 간격으로 확인합니다. 분석 자료는 1시간 유효하며, 만료되면 다시 분석합니다. 보유 모의 종목은 가격 위험을 먼저 확인한 뒤 재무·뉴스를 갱신합니다.

## 판단 방식과 한계

- 매출, 영업이익, 순이익, 자기자본비율, 영업현금흐름을 검사합니다. 영업·순이익 흑자를 필수로 하는 재무 규칙을 사용합니다.
- 최근 7일의 회사명 관련 기사에서 부정·긍정 키워드를 검사합니다. 기사 부재·뉴스 조회 실패·위험 키워드는 신규 매수에서 제외합니다. 규칙 점수는 예상 수익률이나 성공 확률이 아닙니다. 동명이인 기사·문맥 오판·기사 누락 가능성이 있습니다.
- 최신 원화 호가, 정규 매매시간, 호가 차이, 완성된 일봉의 5일/20일 추세를 검사합니다. 추천 선정과 매수 조건 충족은 별개입니다.
- 모의매매는 한 번에 1종목, 하루 신규 매수 1회입니다. 1주 예산이 부족하면 매수하지 않습니다.
- 기본 익절은 비용 반영 10%, 손절 3%, 최대 낙폭 10%입니다. 모의 평가액에는 예상 청산 비용을 반영합니다. 손절 가격·최대 손실의 보장을 뜻하지 않습니다.
- 모의 수수료 0.015%, 매도 비용 예비율 0.4%, 슬리피지 0.1%는 **설정 가능한 가정**입니다. 법정 세율 안내가 아닙니다. 모의 체결은 호가를 이용한 가정으로 실제 체결 가능 물량·대기열을 재현하지 않습니다.
- 실현 손익은 다음 매수 예산에 반영됩니다. 화면의 +10%는 초기 원금 대비 비교 목표이며 기간 수익률 보장이 아닙니다. 주문 상한은 자동으로 늘리지 않습니다.

## 실제 주문은 매번 승인

**자동 승인 알림:** 추천 목록에서 종목을 선택한 뒤 실제 주문 승인 탭의 **선택 종목 승인 알림 시작**을 누릅니다. 모의 실행 없이 사용할 수 있습니다. 조회 완료 후 5초 간격으로 조건을 확인하며, 주문안이 발생하면 승인 팝업이 열립니다. 통신 시간만큼 감지가 지연될 수 있습니다. 팝업에서 승인해야 해당 주문 한 건이 전송됩니다.

거절한 동일 종목·방향·사유는 조건이 해제되거나 알림을 다시 시작하기 전까지 재알림하지 않습니다. 가격·수량만 변경돼도 재알림하지 않으며, 화면의 최신 주문안은 수동 승인할 수 있습니다. **승인 알림 중지**는 감시만 중지하고 이미 전송한 주문은 취소하지 않습니다. 조회 오류 시 감시는 중지되므로 상태 안내를 확인한 뒤 다시 시작하세요. 분석 자료는 자동 갱신하지 않으므로 필요 시 뉴스·재무 분석을 다시 실행하세요.

1. 추천 목록에서 종목을 선택하고 **선택 종목 주문안 / 체결 확인**을 누릅니다. 처음 승인매매를 사용할 때는 보유분·미체결 없는 계좌가 필요합니다. 다른 봇과 같은 계좌에서 동시에 거래하지 마세요.
2. 실제 주문안의 **종목·방향·수량·지정가·금액·비용 가정·판단 사유**를 읽습니다.
3. **표시된 실제 주문 승인**을 누르고 확인창에서 그 주문 한 건을 승인합니다. 승인 전까지 주문은 없습니다. 매도도 별도 승인이 필요합니다.
4. 승인 시 계좌·시장·수수료·호가를 다시 확인합니다. 가격·수량·조건 변경 또는 120초 만료 시 전송하지 않으며 새 주문안과 새 승인이 필요합니다. 시장가는 사용하지 않습니다.
5. **주문안 / 체결 확인**으로 후속 상태를 확인합니다. 주문 접수는 체결이 아닙니다. 최종 체결 비용은 증권사 체결 정산을 사용합니다. 미체결 취소는 **미체결 취소 승인**으로 요청합니다. 프로그램 종료·모의 감시 중지는 실제 미체결 취소가 아닙니다.

확인되지 않은 주문 전송 결과는 자동 재전송하지 않습니다. 토스 앱에서 확인하세요. 기록을 삭제하면 주문·보유분 연결을 잃을 수 있습니다. 승인매매의 예산·위험 설정은 기존 기록과 일치해야 합니다. 종목 변경은 보유분·미체결이 모두 정산된 후 새 종목을 선택해 진행하며 현금·손익·위험 기록을 이어갑니다.

## 기록

- `advisor/paper.json`: 모의 자산·거래·평가 기록
- `advisor/recommendations.json`: 최근 추천과 근거
- `advisor/approved_state.json`: 승인 주문 의도·접수·체결 정산 기록
- `advisor/settings.json`: 모의·승인 분석에 사용한 예산과 비용 가정
- **모의 거래 CSV 저장**: 모의 거래 내보내기
- **모의 기록 보관 후 새로 시작**: 모의 기록만 보관하고 새로운 설정을 적용합니다. 실전 기록은 초기화하지 않습니다.

프로그램을 종료하면 모의 감시도 종료됩니다. Windows 자동 시작 기능은 없습니다. 실제 계좌를 사용한 실거래 체결 검증은 수행하지 않았습니다.
