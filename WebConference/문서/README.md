# 모아 개발 및 사용 문서

2026년 10월 18일, 구현 커밋 fd1a7d0 기준의 문서입니다. 실제 운영 서버에 해당 버전이 설치되어 있어야 설명한 기능을 사용할 수 있습니다.

| 문서 | 읽는 사람 | 원문 | 오프라인 열람 |
| --- | --- | --- | --- |
| 개발상세서 | 개발자·유지보수 담당자 | [Markdown](개발상세서.md) | [HTML](../개발상세서.html) |
| 역할별 사용 매뉴얼 | Master·방장·참석자·서버 관리자 | [Markdown](사용매뉴얼.md) | [HTML](../화상회의_상세매뉴얼.html) |

HTML에는 스타일과 SVG 도표가 포함되어 있어 파일 하나만으로 오프라인 열람할 수 있습니다. 목차 이동·브라우저 검색·인쇄를 지원합니다. 모바일에서 넓은 표와 Flowchart는 가로 스크롤로 읽습니다. GitHub 웹에서는 Markdown 원문을 읽거나 HTML 파일을 내려받아 브라우저로 여세요.

원문 수정 후 프로젝트 루트에서 실행합니다. Python 표준 라이브러리만 필요합니다.

```bash
python 문서/build_documents.py
```

`diagrams/`의 SVG도 같은 스크립트가 생성합니다. 도표를 변경하려면 build_documents.py를 편집합니다. HTML을 직접 편집하면 다음 빌드에서 변경이 사라집니다. 이전 `매뉴얼/build_manual.py` 명령도 새 생성기를 호출합니다. 이전 매뉴얼 폴더의 내용은 과거 운영 참고 자료이며 최신 역할·버튼·기록 절차는 이 문서를 우선합니다.

문서 수정 시 제목·버튼 이름·역할·API·설정값을 소스와 대조하고, `python 문서/check_documents.py`로 링크와 화면을 확인합니다. 이 검사는 로컬 HTML만 열며 운영 서버나 이메일에 접근하지 않습니다. 브라우저 검사는 Playwright와 Chrome이 설치된 개발 Python 환경이 필요합니다. 실제 키·SMTP 비밀번호·승인 토큰은 문서에 넣지 않습니다.
