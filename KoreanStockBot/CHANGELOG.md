# 변경 내역

## v1.0.5 — 2026-10-12

- 공통 버튼을 둥근 모서리·음영·선명한 테두리로 변경.
- 실행(파랑), 저장·적용(초록), 중지(코랄), 안내·그래프(보라)로 구분.
- 마우스 오버·누름·키보드 포커스·비활성 상태를 각각 표시.
- Manual 메뉴 버튼에도 입체 테두리 적용.

## v1.0.4 — 2026-10-12

- 상단 Manual 버튼과 컬러 카드형 오프라인 안내 창 추가.
- 시작 순서, 버튼, 화면 영역, 그래프, 인증 파일, 상태 문구를 6개 주제로 안내.
- 모드별 버튼 설명, 스크롤·자동 줄바꿈·중복 창 방지·Esc 닫기 지원.

## v1.0.3 — 2026-10-12

- 인증·계좌 설정 창에 빈 JSON 템플릿 생성, DPAPI 암호화 변환, 암호화 파일 불러오기 추가.
- 파일은 같은 PC·Windows 사용자에서 복호화하며, 계좌 조회·선택 후 암호화 저장으로 적용.
- 암호화 검증 후 평문 원본 삭제 여부 선택. 잘못된 파일을 불러오면 기존 입력 유지.

## v1.0.2 — 2026-10-12

- 모호한 `n초 전`을 `마지막 상태 수신 후 경과: n초`로 변경.
- 새 상태 수신 시 0초로 갱신됨을 화면에 안내.
- 최초 응답 전에는 `첫 상태 수신 대기: n초 경과`로 구분.

## v1.0.1 — 2026-10-12

- 프로그램·수익률 그래프 창 제목, 실행파일명, Windows 파일 속성에 버전 표시.
- 기본 빌드마다 기존 버전 폴더를 확인하여 다음 패치 버전으로 배포.
- 계좌 선택 목록, 키 보기/숨기기, 앞뒤 공백 제거 기능 포함.
- 휴장·개장 대기·연결 오류 및 마지막 상태 수신 시각 표시 포함.

배포 위치: `Release/v1.0.1/KoreanStockBot`.
기존 버전의 설정·거래 기록은 자동 이동하지 않습니다. 기존 운용을 이어가려면 종료 후 동일한 설정과 runtime 기록을 함께 옮겨야 합니다.
