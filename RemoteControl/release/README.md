# RemoteControl v0.4.5 배포 패키지

다른 스마트폰/갤럭시탭과 새 Ubuntu 서버에 설치하기 위한 묶음입니다.

1. `manual/01_설치_매뉴얼.md`를 읽고 서버 인증서와 새 설치를 준비합니다.
2. Host / Target APK를 해당 기기에 설치합니다. 둘 다 v0.4.5로 맞춥니다.
3. `manual/02_사용_매뉴얼.md`에 따라 서버 연결, 공유 승인, Host 연결을 진행합니다.

매뉴얼은 같은 이름의 HTML 파일로도 제공됩니다. 브라우저에서 열어 읽거나 인쇄/PDF 저장할 수 있습니다.

APK는 현재 프로젝트의 Debug 서명본(버전 코드 9)이며 정식 스토어 배포용 서명본이 아닙니다. 인증서·서버 접속 키·서명 개인키는 포함하지 않습니다. 새 서버 설치 때 서버 접속 키를 생성합니다. 앱에 표시되는 기존 서버 주소를 새 서버 주소로 변경하세요.

서버만 복사할 때는 `RemoteControl-server-v0.4.5.tar.gz`를 사용하세요. 전체 전달용 ZIP은 이 폴더 안의 `RemoteControl-v0.4.5-installation.zip`입니다. ZIP에는 중복 압축을 피하기 위해 ZIP 자체를 제외한 전체 파일이 들어 있습니다.

파일별 무결성은 `SHA256SUMS.txt`, 전체 ZIP 무결성은 `BUNDLE-SHA256.txt`로 확인합니다. 세부 제작/검증 정보는 `BUILD_INFO.txt`에 있습니다.
